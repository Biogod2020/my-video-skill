# Dirty Medicine 个人音色长课生成规范

本规范定义医学长课连续语音生成的工程标准与质检底线，适用于医学口播课程及讲义语音制作。

## 1. 原生连续生成与工程参数基线
- **连续生成基线**：冻结底模与 codec revision（当前工程基线采用 MOSS-TTS-v1.5 8B 底模与匹配 codec），使用已授权同一参考声与干净、节奏合适的教师 continuation 前缀，采取整篇原生连续生成，无 LoRA、无整轨拉伸、无逐页独立声块。
- **核心不可推断工程参数**：
  - MOSS-TTS-v1.5 当前冻结版本的 codec 约为每秒 12.5 帧。
  - 时长条件 `tokens` 包含前置上下文帧数；`max_new_tokens` 为新增生成步数预算，需结合目标新增音频时长、延迟模式收尾及安全余量进行设置。
  - **适用边界**：上述参数仅适用于当前冻结的 MOSS-TTS-v1.5 变体，严禁盲目外推至其他模型或新版本。
- **基线替换门槛**：微调模型或小幅调速仅在控制变量的代表性完整长稿盲测胜出后方可替换当前基线；固定 seed 无法补救单段语气生硬；劣质上下文会传导坏节奏。若调整语速，必须保留原始音轨、完整记录处理过程并重新计算所有字幕与画面时间。记录文本 hash、参考音 hash、前缀 hash、模型版本、seed、环境及实际音频时长。
- **时长预算动态校准**：音频目标时长必须按字数与认知负荷动态校准，而非机械重用旧视频时长。完整性判断必须联合核验结尾句闭合、全文关键信息覆盖及 EOS 终止符，不得仅以未触及最大 token 上限断定生成完整。

## 2. 文本分离与医学审读
- **口播与屏显分立**：严格区分屏显中英讲义与单独的 `spoken_text`。屏显保留标准中英文术语与复合单位；口读文本按语义改写易误读的连接符与单位，保留真正的负号与数值（如“葡萄糖六磷酸”、“克每分升”），数值严格保持一致。
- **专有名词与缩写核对**：对医学英文缩写及易混淆同音表述，必须结合实际发音人工或模型听审核实。ASR 同音字不作为误读证据，不能仅按 ASR 文本盲改医学结论。

## 3. 停顿教学目的与自动校准
- **停顿服务于教学**：普通转场使用短气口（如 0.35 秒），复杂生化反应留出理解吸收时间，正式练习题作答前留足安静思考期并配合动态倒计时胶囊栏。
- **静音校准与波形复核**：原生暂停指令无法保证精准秒数。基于 ASR 字符对齐与波形静音分析定位题前停顿区间；仅在已确认的安静区间补足纯静音，禁止词中截断，并导出帧级映射供画面与字幕同步。保留所有发声采样，严禁段段归一化或掐字。
- **答案揭晓缓冲**：思考倒计时结束后，口播先给出自然过渡句（如“好，我们来看答案”），待说到选项或关键结论时才在画面上高亮答案，消除抢跑催促感。

## 4. 片尾稿外音教训与本地 Guard
- **片尾稿外音教训**：长课即使模型输出正常 EOS、全文 ASR 覆盖率极高且无明显差异，结语后仍可能存在 ASR 未捕捉的真实稿外音（波形活动证实）。必须建立自动化筛查与听审闭环。
- **本地 Guard 规范**：
  - 在末 ASR 词结束时间后设置 0.5 秒宽限期。
  - 从宽限期结束至音频末尾，以 20ms 为窗口、-45dB RMS 为阈值进行能量扫描。
  - 若超出阈值的音频活动累计达到或超过 0.3 秒，自动标黄 `review_required: true`，提示必须听审。
- **Guard 执行底线**：Guard 仅是物理能量活动阈值，不证明存在语音，**绝不能自动裁切**；正常轻微呼吸不算错误。处理首尾异响必须保存原轨，在核实结语后才在确认安静区裁切。
- **时间戳与对齐复用**：纯尾部裁切且保留区间起点不变时，可直接复用已核验的词级时间戳，更新文件 hash 并验证时间边界；若涉及头部裁切、插入静音或改变正文，则必须重新导出帧映射或重做对齐，不能无条件要求仅删已核实稿外尾音也整课重跑 ASR。

## 5. 独立盲听审听与评审反证
- **盲听隔离**：审听模型直接接收生成音频，严禁提供参考真声、字幕、模型身份或历史评分。由 Gemini/agy 直接听审，引用开头、中段、后段和末尾的实际发声词句与时间戳。
- **自动化与模型互补**：技术静音分析与 ASR 覆盖率检查属于工程质检，不能替代真实的模型听审。
- **反证核对与真实修复**：对模型批评必须用实际帧、ASR 和源音波形交叉反证。若模型误判，核实证据后坚决保留正常发音与正确拼写，绝不为了迎合报告切碎长音轨；仅针对证实的真实缺陷进行修改，并在更正后重新验证实际交付文件。
- **安全与授权**：遵循项目既有参考音频长期授权，私声参考音只用于已授权的推理环境，不公开原始录音、真实参考音 hash 或凭证。
