# Dirty Medicine 个人音色长课生成规范

本规范定义医学长课连续语音生成的工程标准与质检底线，适用于医学口播课程及讲义语音制作。

## 1. 原生连续生成与工程参数基线
- **连续生成基线与冻结 Recipe**：沿用实际已获认可的冻结 recipe。英文课程默认使用底模 MOSS-TTS-v1.5 8B 原生连续生成（`adapter_loaded=false`），不加载 LoRA adapter，中文课程已验证的 LoRA 权重保持独立有效且不因此废弃；英文配合已授权同一参考声与既有英文教师 continuation 前缀（约 20 秒，251 frames），本轮生成 seed 为 42，整课一次原生连续生成，实际 `Instruction=None`（严禁将 profile goal 元数据误写为模型风格指令）。初次整课生成严禁逐页独立分块拼接；局部改稿按用户请求范围处理，另列修复派生版本。说明可复现输入与配置，不保证跨硬件位级完全相同。
- **预算分离发声时长与原生静音**：时长条件预算公式必须将**纯发声时长**与**观测到的原生静音/停顿余量（quiet allowance）**解耦分离计算（同一计数口径下的公式参考：`口播代理单位数 × 60 / 原生目标发声速度 + 观测原生静音余量`）。静音余量从相同授课风格的代表性长轨实测估计；已包含的正式题留白不再重复计入。明确时长条件 `duration tokens` 是给模型的软性时长引导条件，而非硬性截断或精确物理保证；当前仍保持时长条件引导（历史完全移除时长条件的测试并未稳定提升同语速自然度）。
- **时长条件与步数上限 Cap 解耦**：Codec 帧率约为 12.5 帧/秒。时长条件 `duration tokens` 包含前置上下文帧数；`max_new_tokens` 为生成步数安全上限（Cap），需兼顾目标音频、延迟模式收尾与保守余量；总位置（实际输入位置数 + max_new_tokens）须在模型总上下文窗口（当前冻结版本为 40960）内留有充足裕量。
- **实际 Adapter 与输入严格对照**：如实记录 base revision、codec revision、实际加载的 adapter 标识及全部生效生成参数；同时记录真正传入的模型 instruction，不把 profile 中的 goal 元数据当成风格指令。私有记录必须完整留存 raw/normalized/effective 讲稿及实际编码 `input_ids` 的 hash 对照。换行规整器意味着单纯换行排版不一定自动生成停顿；在修改讲稿时，固定 seed 亦无法保证未修改段落保持原样不变。
- **基线与派生轨严密管理**：冻结当前 recipe 旨在确保产出一致性，不封闭未来受控改进，亦不提倡无休止盲目刷 seed。根据实测发声速度计算的小幅 tempo 校准轨与原生基线轨分立管理，完整记录处理链路并重新映射字幕时间线。交付前必须对最终完整音轨重新执行全量核验。完整性判断必须联合核验结尾句闭合、全文关键信息覆盖及 EOS 终止符，不得仅以未触及最大 token 上限断定生成完整。
  - **适用边界**：上述参数仅适用于当前冻结的 MOSS-TTS-v1.5 变体，严禁盲目外推至其他模型或新版本。

## 2. 文本三层映射与医学发音审读
- **三层文本映射架构**：建立规范屏显讲义、自然口语（`spoken_text`）与 TTS 模型输入（`tts_input`）的三层映射追踪机制。屏显保留标准中英专名与符号；`spoken_text` 按自然口语表达（如 Pi 首次交代中文全称与屏幕字母，后续自然使用中文全称，不机械重复全称）；`tts_input` 仅在发现发音缺陷时进行局部发音辅助（如短语级同音字代换），严格记录替换范围、前后字词及依据，讲稿与字幕保持正字，严禁全局替换冷僻汉字。
口读文本按语义改写易误读的连接符与单位，保留真正的负号与数值（如“葡萄糖六磷酸”、“克每分升”），数值严格保持一致。
- **专有名词与缩写核对**：生成前梳理高风险缩写、数字单位和医学易错字预期发音清单；生成后必须结合实际完整音频进行专项听审，逐一核实各出现位置的发音。ASR 同音字转写仅作为内容参考与定位辅助，不可单独作为误读或正读证据，严禁仅按文本转写盲判发音。

## 3. 停顿教学目的与自动校准
- **同语言统一语速与停顿标准**：所有课程在同一语言下共享统一的配置文件、配置版本、计数口径、扣除静音后的发声速度目标以及句末、设问、转场、正式题目等停顿区间。严禁在工程代码中硬编码固定倍速（如机械固化 1.25x）；各轨先测量扣除静音后的发声速度；已获认可且符合当前标准的原生轨保持原速，确有校准需要时才计算派生轨倍速，不同倍速不等于执行标准不同。整段总时长或每分钟字数不可替代发声速度，因为正式题与机制留白等静音在各课中占比不同。
- **计数口径与自然区间原则**：中英文采用不同计数口径；中文及中英混读采用规范的代理单位计算，严禁宣称精确音节。各类停顿设置合理的自然浮动区间，严禁一刀切设定死板相同秒数，严禁在每个逗号处机械加长。已有获得认可的课作为参照，当前统一标准的候选目标数值只在项目配置中集中管理与迭代，严禁将具体数字硬编码成普适医学课规范。
- **停顿是全篇正文的教学结构**：停顿服务于初学者的认知负荷，绝不局限于正式试题前的思考留白。停顿节点覆盖：完整句意阐述结束、密集生化名词与连续动作交代之后、生理/病理关键因果转折处、设问抛出后至答语给出前、引导学生视线观察左右图解/换页/引入新题目之时。普通连贯讲述句不统一机械加长；医学专有复合词内部、同一个尚未讲完的催化动作内部严禁切断；完整动作结束后，按认知负荷与配置区间留白。
- **不依赖 LLM 的工程节奏校准**：节奏校准与数值计算采用[确定性工程算法](../scripts/standardize_course_pacing.py)，所有发声速度计算、静音测量与时间线重对齐均不需要 Gemini 决策或预先批准：
  - **测量电平与速度口径一致**：在进行发声速度测量前，必须先通过静态增益标准化电平，避免电平差异改变低能量统计分布；随后采用统一固定的 RMS 分析窗口（如 20ms）、能量阈值（如 -43dB）与最短静音持续时间（如 0.18s），结合规范的代理计数口径测算纯发声速度；计算得出的小幅 tempo 须在编码封装后重新对最终母带测算确认。
  - **保留普通停连与保护原轨**：经认可的 TTS 原生配音发声与自然停连默认保持，默认无全局 tempo、无逐句 R3 时间拉伸、无逐逗号自动静音标准化；工程测速筛查持续运行，但线索不直接自动修改。用户授权在少数完成句意、机制转折、引导看图或正式题处补足认知留白。留白必须只能在波形证实的纯安静中心补差，严禁裁剪呼吸、严禁切断词句，严格保留源 PCM 顺序，不按每句或每页机械加白，仅为加留白不重生成 TTS 发声片段。严禁词中截断，剪裁与插留白保护相应处理阶段的有效发声采样、医学术语与连续动作；tempo 或增益处理不宣称与原生 PCM 逐采样相同。
  - **多源共同验证**：静音与语段边界必须由已有讲稿、词级时间戳与实际波形共同验证。
  - **低置信度原样保留**：凡属于低置信度的边界或发音，原样保留并列为待核对项，严禁编造“已全部达标”。
  - **微弱呼吸保护**：说话人自然的微弱生理呼吸不得因局部 RMS 低就误判为死寂并粗暴裁掉；仅允许在波形确认接近数字零的中部纯安静区执行剪裁或留白插入。
- **三要素解耦与原声韵律底线**：严格区分三项独立的声音要素，严禁混淆：
  1. **发声速度**（扣除静音后单位时间的纯发声快慢，中文混读使用代理单位，不宣称精确音节）；
  2. **句间认知留白**（语意结束后的气口吸收与思考缓冲）；
  3. **原声重音与韵律顿挫**（母带发音的语气起伏、重音分布与内在顿挫感）。
  - **底线要求**：插入物理纯静音**绝对无法伪造原本缺失的语气、重音与顿挫**；发声速度与停顿指标达标，**绝不能自动证明初学者实际听感通过**。若核验发现讲稿语气或衔接导致原生配音缺乏顿挫，交由 agy 整合受影响讲稿上下文，使用 TTS 重新原生连续生成。严禁试图通过大幅机械拉伸或在每句话后粗暴塞入大空白来掩饰韵律缺陷；基于实测发声速度进行的小幅工程 tempo 属于受控校准，与掩饰韵律缺陷有本质区别。
- **局部速变与短窗冲快检验**：全课平均发声速度与整句平均 WPM 达标，绝不能作为放行局部突然冲快或突兀抢拍的依据。局部语速突变与短窗冲快的数值定位完全由确定性工程脚本负责（采用词级 ASR、扣除静音的音节代理比率及多窗比对，详见 [local-pace.md](local-pace.md)），严禁为此调用 Gemini 进行数值测速或依赖其批准。脚本排查出的候选仅为待复核线索（`review_candidate_not_confirmed_defect`），绝非确诊缺陷，严禁将其自动机械修成平速。Codex 与人工结合前后文（如前后 4 秒）、ASR 定位与波形进行上下文复听研判；常用功能词与短语天然发声较快，严禁按机械逐词速度一刀切判错，严禁在紧密主谓（如 liver 与 must）之间强插停顿切断语流，更严禁通过局部拉伸掩盖原生韵律。质检必须先研判文字可讲性、模型原生韵律波动与工程处理三者来源：若讲稿本身通顺自然且医学事实无误，严禁因局部声音缺陷盲目倒逼改文；排查应先以波形与时间线证据排除工程处理引入；确属原生韵律缺陷且需修复时，按用户请求范围与既有授权沿用冻结基线生成有限同上下文完整长轨重新送审。当前问题音频在未获全轨实听与用户确认前，严禁虚报通过或已修复。
- **全链路时序映射与母带封装**：
  - **双轨独立管理**：严格区分 TTS 原生母带与经授权构建的剪辑派生母带（稀疏留白派生或校准轨），分立管理并独立计算 hash。派生母带基于可回滚的 sample 级 EDL 构建，可随时无损回退原生轨；制作、工程验证、Gemini 听审与用户接受分别记录，未执行的步骤不得标为完成。
  - **全链路统一映射**：所有字幕 cue、动态高亮、章节切换、思考倒计时与 quiz 校验必须严格统一使用同一套交付速度与采样级/帧级时序映射重算；字幕在留白中的呈现须随教学用途设计，题页留白严禁提前泄露答案。
  - **渲染底线**：视频渲染器只直接封装已通过审核的最终音频母带（已审原生母带或已审派生母带），渲染器本身严禁私自二次调速、重新增益或拼接加工。
  - **答案揭晓缓冲**：思考倒计时结束后，口播先给出自然过渡句（如“好，我们来看答案”），待说到选项或关键结论时才在画面上高亮答案，消除抢跑催促感。
- **最终多模态实听质检与初学者放行标准**：工程节奏校准与局部语速突变筛查完全由确定性工程算法负责，严禁为数值测速或阈值判定额外调用 Gemini；若 Gemini 听审偶然指出语速急促，应返回工程测量与人工上下文复听，不把 LLM 估算作为数值裁决。但最终导出的整轨音频与完整 MP4 视频**仍必须全量送交 Gemini/agy 执行真实的视听质检**，落实初学者节奏验收结论：
  - **核心判据**：初学者能否听懂上一层生化机制动作并看清对应画面图解，再从容进入下一层？
  - **具体检验**：句末语调是否自然落稳、是否具备正常生理呼吸、设问后的回答是否非抢答抢跑、复杂生化路径转折是否与上下文连贯、整体听感是否从容不赶且非机械死寂。
  - **送审实据**：实际生成的新整轨音频与实际导出的新完整 MP4 必须全量送审，审核回执必须明确引用开头、中段、后段和末尾的真实发声台词与时间戳。严禁用“发音清晰”、“无错字错词”或抽象的“模型 PASS”替代节奏维度的实质检验。
- **用户反馈一票否决与版本隔离**：
  - **反馈即否决**：用户明确反馈“感觉太赶”、“顿挫不足”，即判定当前交付版本在该维度**未通过**。完整保留历史审核记录，严禁辩解或否认用户真实感知。
  - **盲听对照核验**：针对原版与改版实际完整媒体执行盲听对比，提取具体听觉实例，验证节奏是否切实改善，并核查是否引入不自然长暂停、音色漂移或破音。
  - **成因与观察严密区分**：必须严格区分“模型听觉观察”（如新轨改善仓促感）与“模型成因推测”（如误判时长变化全来自停顿而忽视倍速改变）；成因判断必须以代码配置与波形实际测算为准。
  - **派生稿独立审核与防移植**：每课独立管理版本配置与媒体 SHA256；新制作或派生的音视频稿件必须独立执行工程校准与完整送审，历史通过回执严禁移植到新版本。
  - **实验状态客观说明**：候选完成工程校准不代表已获用户听感验收；在未获用户明确评价前，不宣称用户已接受或问题已解决。

## 4. 收束完整性、正文重复排查与本地 Guard
- **收束与重复教训**：长音频即使模型输出正常 EOS、全文 ASR 覆盖率看似达标，仍可能存在两类隐蔽缺陷：一是结语后存在真实稿外发声；二是长轨中出现正文段落回放、漏读或异常重复。片尾 Guard 无法覆盖正文内部重复，必须增设文本顺序、回环重复及正确收束的系统性核对。自动重复检测候选须人工或模型复核，避免将正常的教学复盘或总结误判为异常重复。
- **本地 Guard 与重复修剪规范**：
  - 在末 ASR 词结束时间后设置 0.5 秒宽限期，从宽限期结束至音频末尾以 20ms 窗口、-45dB RMS 阈值进行能量扫描；活动累计 ≥0.3s 自动标黄 `review_required: true`。
  - 确认存在非预期重复或多余尾巴时，保留完整原生音轨，仅在波形确认的纯安静边界处修剪证实的多余部分；严禁将整体音频切碎为独立短句重录。
- **Guard 执行底线**：Guard 仅是物理能量活动阈值，不证明存在语音，**绝不能自动裁切**；正常轻微呼吸不算错误。处理首尾异响必须保存原轨，在核实结语后才在确认安静区裁切。
- **有效采样映射与对齐更新**：修剪后必须保留全部有效发声采样，导出采样级分段映射，并严格校验留存 PCM 连续性、词边界及关键信息完整性。若拥有可信的分段映射与时间平移关系，直接更新对应字幕与 cue 时间戳，无需盲目对全课无条件重跑 ASR。

## 5. 独立盲听审听与评审反证
- **有限完整候选与全量盲听实践**：避免无休止试错与刷 seed，每次试验产出有限数量（如 2 个）的完整长轨候选，在同一测速口径与相近响度下，与基线版本匿名混合（如 P/Q/R，严格隔离模型/seed 标识、字幕、真声及历史打分）送交全量盲听；审听必须接收实际完整长音频并引用开头、中段、后段与结尾的具体词句及近似时间戳；记录实际媒体附件字节数与 SHA256 回执，核对所引台词与各轨自身的有效讲稿；不同稿本的措辞差异不报成漏读。最终交付文件必须与已核验且用户未否决的选中导出音频逐字节一致；再加工版本重新送审。
- **双轨审听制**：质检实行双轨制：
  1. **自然度盲听**：审听模型接收完整音频，全面审查语速、自然度、语气连贯、全篇停连呼吸与整体听感；
  2. **专有名词与易错字专项审听**：生成前提供高风险缩写、复合单位及易读错生字词的预期发音清单；专项审核必须接收实际完整长音频，逐次核对各时间点的实际发声，报告清晰度与不确定处。严禁以字幕正确代替实际听音，严禁用短样本试听或平均音质分代替全课核验。
- **自动化与模型互补**：技术静音分析与 ASR 覆盖率检查属于工程辅助，不能替代真实的多模态听审。
- **反证核对与真实发音判定**：对模型批评必须细分“实际观察”、“成因推测”与“处理建议”：
  - 审听模型报告的时间戳仅供近似定位，实际静音与停顿长度必须以波形客观测量为准；
  - ASR 同音字转写（如英文字母 G /dʒiː/ 转写为中文“基/鸡/计”）绝不能直接作为发音错误证据；提取实际音频结合英文字母规范读音核验，核实无误坚决撤销伪报错；
  - 面对同一媒体的互相矛盾的评审意见（如同一文件 SHA 在不同轮次报告互斥结论），必须回到实际音频与既有核验记录复核，严禁直接作为淘汰或重录依据；局部截帧/截取核验仅作为全局审听的辅助，绝不替代全长音频听审；
  - 讲稿规整歧义（如生化位点数字与中文表述）应在后续稿件中由 agy 统一正名，严禁对已获用户认可的成片音轨做切碎打补丁式的无谓重录。改稿必须由 agy 通盘整合上下文。
