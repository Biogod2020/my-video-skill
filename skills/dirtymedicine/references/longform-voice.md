# Dirty Medicine 个人音色长课生成规范

本规范定义医学长课连续语音生成的工程标准与质检底线，适用于医学口播课程及讲义语音制作。

## 1. 原生连续生成与工程参数基线
- **连续生成基线**：冻结底模与 codec revision（当前工程基线采用 MOSS-TTS-v1.5 8B 底模与匹配 codec），使用已授权同一参考声与干净、节奏合适的教师 continuation 前缀，采取整篇原生连续生成，无 LoRA、无整轨拉伸、无逐页独立声块。
- **核心不可推断工程参数**：
  - MOSS-TTS-v1.5 当前冻结版本的 codec 约为每秒 12.5 帧。
  - 时长条件 `tokens` 包含前置上下文帧数；`max_new_tokens` 为新增生成步数预算，需结合目标新增音频时长、延迟模式收尾及安全余量进行设置。
  - **适用边界**：上述参数仅适用于当前冻结的 MOSS-TTS-v1.5 变体，严禁盲目外推至其他模型或新版本。
- **基线替换门槛**：微调模型或小幅调速仅在控制变量的代表性完整长稿盲测胜出后方可替换当前基线；单次生成通过（如特定 seed 或别名组合）属多因素共同结果，不能主观归因为单一变量生效，亦严禁将单次试验的 seed、硬件或倍速设为全局强制默认；劣质上下文会传导坏节奏。若调整语速，必须保留原生基线轨并与派生变速轨分立管理，完整记录处理过程并重新计算所有字幕与画面时间。记录文本 hash、参考音 hash、前缀 hash、模型版本、seed、环境及实际音频时长。新生成音轨随时可能引入全新发音或时序缺陷，交付前必须对实际完整音轨重新执行全量核验。
- **时长预算动态校准**：音频目标时长必须按字数与认知负荷动态校准，而非机械重用旧视频时长。完整性判断必须联合核验结尾句闭合、全文关键信息覆盖及 EOS 终止符，不得仅以未触及最大 token 上限断定生成完整。

## 2. 文本三层映射与医学发音审读
- **三层文本映射架构**：建立规范屏显讲义、自然口语（`spoken_text`）与 TTS 模型输入（`tts_input`）的三层映射追踪机制。屏显保留标准中英专名与符号；`spoken_text` 按自然口语表达（如 Pi 首次交代中文全称与屏幕字母，后续自然使用中文全称，不机械重复全称）；`tts_input` 仅在发现发音缺陷时进行局部发音辅助（如短语级同音字代换），严格记录替换范围、前后字词及依据，讲稿与字幕保持正字，严禁全局替换冷僻汉字。
口读文本按语义改写易误读的连接符与单位，保留真正的负号与数值（如“葡萄糖六磷酸”、“克每分升”），数值严格保持一致。
- **专有名词与缩写核对**：生成前梳理高风险缩写、数字单位和医学易错字预期发音清单；生成后必须结合实际完整音频进行专项听审，逐一核实各出现位置的发音。ASR 同音字转写仅作为内容参考与定位辅助，不可单独作为误读或正读证据，严禁仅按文本转写盲判发音。

## 3. 停顿教学目的与自动校准
- **停顿服务于教学**：普通转场保持自然生理气口，仅按读图、机制转折与做题思考校准必要留白，不统一拉长区间。单课实测数据（如读病例 2.3 秒、作答 3.6 秒或 5 秒）仅为该课认知负荷下的实测值，并非全局通用硬指标。
- **静音校准与波形复核**：口播文本标注的 pause 并非物理秒数保证，实际留白应按最终交付语速进行波形测量。基于波形静音分析定位停顿区间；仅在确认的安静区间补足纯静音，禁止词中截断，并导出采样级/帧级映射供画面与字幕同步。除经实证确认的非预期重复剪除外，原则上保留所有有效发声采样，严禁盲目掐字或分段归一化。
- **答案揭晓缓冲**：思考倒计时结束后，口播先给出自然过渡句（如“好，我们来看答案”），待说到选项或关键结论时才在画面上高亮答案，消除抢跑催促感。

## 4. 收束完整性、正文重复排查与本地 Guard
- **收束与重复教训**：长音频即使模型输出正常 EOS、全文 ASR 覆盖率看似达标，仍可能存在两类隐蔽缺陷：一是结语后存在真实稿外发声；二是长轨中出现正文段落回放、漏读或异常重复。片尾 Guard 无法覆盖正文内部重复，必须增设文本顺序、回环重复及正确收束的系统性核对。自动重复检测候选须人工或模型复核，避免将正常的教学复盘或总结误判为异常重复。
- **本地 Guard 与重复修剪规范**：
  - 在末 ASR 词结束时间后设置 0.5 秒宽限期，从宽限期结束至音频末尾以 20ms 窗口、-45dB RMS 阈值进行能量扫描；活动累计 ≥0.3s 自动标黄 `review_required: true`。
  - 确认存在非预期重复或多余尾巴时，保留完整原生音轨，仅在波形确认的纯安静边界处修剪证实的多余部分；严禁将整体音频切碎为独立短句重录。
- **Guard 执行底线**：Guard 仅是物理能量活动阈值，不证明存在语音，**绝不能自动裁切**；正常轻微呼吸不算错误。处理首尾异响必须保存原轨，在核实结语后才在确认安静区裁切。
- **有效采样映射与对齐更新**：修剪后必须保留全部有效发声采样，导出采样级分段映射，并严格校验留存 PCM 连续性、词边界及关键信息完整性。若拥有可信的分段映射与时间平移关系，直接更新对应字幕与 cue 时间戳，无需盲目对全课无条件重跑 ASR。

## 5. 独立盲听审听与评审反证
- **盲听隔离与专项审听双轨制**：完整长音频即使送审模型仍存在单音节或微弱词位漏检的可能（如长课中多处缩写单音节未被普通审核捕获）。质检实行双轨制：
  1. **自然度盲听**：审听模型接收完整音频，严格隔离参考真声、字幕、模型信息及历史评分，全面审查语速、自然度、语气连贯与整体听感；
  2. **专有名词与易错字专项审听**：生成前提供高风险缩写、复合单位及易读错生字词的预期发音与文本出现位置清单；专项审核必须接收实际完整长音频，逐次核对各时间点的实际发声，报告清晰度与不确定处。严禁以字幕正确代替实际听音，严禁用短样本试听或平均音质分代替全课核验。
- **自动化与模型互补**：技术静音分析与 ASR 覆盖率检查属于工程辅助，不能替代真实的多模态听审。
- **反证核对与真实修复**：对模型批评必须细分“实际观察”、“成因推测”与“处理建议”。用实际渲染帧核验字幕显示、用听音核验发音、用波形核验边界。若模型误判（如将正确的生僻字字幕误报为错别字，或将原生重复误判为剪辑拼接），核实证据后坚决反证并保留正确音画，停止多余重做；仅针对证实的真实缺陷进行修复，并在更正后重新全量验证实际交付文件。模型时间戳仅作为近似定位，不声称逐采样确认或真人试验。
- **安全与授权**：遵循项目既有参考音频长期授权，私声参考音只用于已授权的推理环境，不公开原始录音、真实参考音 hash 或凭证。
