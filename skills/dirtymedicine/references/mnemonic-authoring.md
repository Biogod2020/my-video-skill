# 记忆钩子创作工作流（mnemonic-authoring）

用于 dirtymedicine 课程中需要记住名字的考点。目标是一幕只用少量元素，老师讲解一次后，学生能凭画面想起考试名词。不要求每页都有口诀。

## 0. 运行规则
- 本 skill 的全部文字由 agycli 起草。Codex 负责收集证据、核对事实与映射，并做针对性修订，不整体重写。
- 本机调用 agy 前，必须在同一个 shell 进程里先执行 `proxy`：`zsh -ic 'proxy; agy ...'`。模型采用用户选择的 `gemini-3.8-flash-high`。
- 参考课程全文保留在私有工作区；按用户授权提供给写作或审核会话：不提交仓库，不写进 skill，不在公开输出中大段引用。skill 里只保留来源 id、时间点和一句结构说明。
- 用户对同一参考音、同一课程制作用途的授权具有长期效力，不重复提问；项目目录信任不等于所有私人素材外发授权。
- 不自评分数，不写“保证记住”“绝佳”，不把模型评审说成真人测试。

## 1. 选定记忆目标
1. 列出本课考试和课程的重要难点。不要给每页或每个酶硬分配口诀，不规定每课数量，无需口诀就正常讲，0 候选不等于失败。分成 hook 和 diagram 两类：
   - **hook**：考试的重要难点（不限名字，也包括容易记反的方向、固定顺序或配对），只有在通过机制图/对照理解之后，脱离机制仍难想起或容易串错，且联想能带来净记忆收益时才做 hook。
   - **diagram**：重要但能看懂、可通过机制推导的内容。例如通路、酶的作用方向、鉴别对比。这些内容应先用图解、对照、练习和自然重述来解释；术语本身说明作用的（如还原酶负责还原）先直白解释术语，不加比喻。
2. 为每个 hook 写明目标类型：记名字、准确拼写、配对或固定顺序等。
3. 只有拼写目标需要逐字核验字母，检查有没有多出、缺失或暗中跳过的字母。数字或字母如果原样保留、不经拼音转换，要明说。其他目标可以用学生已学过的俗名、英文名或近音作入口。

## 2. 读全文，拆正例
1. 确认每份来源都标为 `STATUS=COMPLETE`。缺了就写“缺失”，不用摘要冒充全文。转写错误不能当事实，品牌和医学事实要另行核验。
2. 创作前先填正例拆解表，只学结构，不照抄句子：

| 正例（来源/时间点） | 线索 | 考试词 | 连接类型 | 跳数 | 同框的东西 |
|---|---|---|---|---|---|
| DM-glutathione 13:20–14:10 | #6 quarter pounder / Heinz / bite | G6PD / Heinz bodies / bite cells | 字形重排 / 品牌同名 / 吃汉堡的固定动作 | 各 1 跳 | 一个汉堡、一瓶酱、咬一口 |
| 本课实测有效示例（G6PD） | 六个皮蛋 / 亨氏番茄酱 / 咬一口 | G6PD / Heinz 小体 / 咬痕细胞 | 盘中5个+筷子1个=6，6GPD换位置=G6PD；品牌同名；吃饭动作 bite | 各 1 跳 | 一盘皮蛋、一瓶番茄酱、咬了一口 |
| DM-Heavy-Metals 31:25–31:40 | mango / basil | manganese / basal ganglia | 准确近音 | 各 1 跳 | 两种食材 |
| DM-Court-Cases 02:05–02:30、03:20–03:45 | dwarf 旁站着 superior / salGO 绿灯，车身写 Consent | Schloendorff 与 respondeat superior / Salgo 与 informed consent | 近音，再把原词写在画面里钉住考点 | 1 跳 | 一个角色或一辆车 |
| DM-Heavy-Metals 02:05–02:30 | arse / breath / poo | arsenic / 大蒜味口气 / 米泔水样腹泻 | 粗俗近音，一句话带出两条线索 | 1 跳 | 一句话 |

3. 从表中总结本课能借用的结构（例如“一件物品带两个考点”“原词直接写在物体上”）。

## 3. 多路径找载体
1. 先尝试几条不同路径的备选，再从中挑选，不把第一句直接扩写成故事。可选路径有：中文俗称或别名；品牌中文名或包装上的英文；课文、经典台词、国民级作品；日常惯例和物件本来就有的动作；准确的中英近音、字形或拼音首字母。
2. 优先选择同名、同字、可解释的近音、字形或固有动作，使学生在一次讲解后能直接找回考试词。如果学生得先记住“谁代表什么”（例如给司机、婴儿或某个角色起医学名字），通常增加了额外记忆负担，应优先改换载体。
3. 社会梗做删词测试：删掉梗后连接仍然成立，说明它只是装饰，删去；删掉后连接就断，才保留。
4. 找不到合格载体时，写明是哪个实体、试过哪些路径、在哪里断掉。允许空结果。

## 4. 压缩成一幕与语气整合
- 用一个本来就成立、或荒诞但一眼能懂的画面。角色不超过 2 个，同框扣住 2–3 个考试实体。可以有正常背景，背景元素不必都是考点。
- **保留已认可载体**：一旦某个载体获得用户认可，必须保留核心载体，将其与前后文一起交给 agy 整合语气并连读验收；严禁因另一轮候选措辞更正式就轻易抹掉已认可的故事，也不必把生化机制和每页摘要都包装成口诀。
- 近音、字母重排、拼音首字母、对原词的最小改写，每种变换只讲一次，并在画面上用清楚的字母或拼音标出。不编错正式术语读音。
- 口播分三段：先用一句人话描述画面，再给每个映射一个短句，最后用一句话转向机制页。简单钩子宜短，不写押韵诗，不用推销腔。

## 5. 机制与记名字分工
- 名字钩子页只负责让人想起名字。机制、诊断地位、诱因、遗传方式放到单独的机制页讲。
- 不编科学寓言（如“番茄酱就是变性蛋白”），也不把病理过程缩成画面（如“脾脏咬出缺口”）。
- 只有画面具体表示了错误机制或错误的诊断地位才修改。食物画面和正常吃饭动作不加免责声明。

## 6. 独立匿名评审
- 另开会话或换一个模型评审。只传入：画面描述、teaching_lines（一次讲解的内容）、映射表、事实、拒绝清单和已登记的反例。不传创作者的 known_tradeoff、辩护、模型身份和候选来源。
- 评审使用附录 B。结论只有“仅供试讲”或“淘汰”，附一句具体理由和失败类别，不打分。

## 7. 失败后定向修改
| 失败类别 | 改法 |
|---|---|
| 断链（某个目标词想不起来） | 只换这一个实体的载体，或把原词写到画面里的物体上 |
| 绕远或增加额外记忆 | 删掉中间角色或中间步骤，改用同名或固有动作 |
| 字母或读音错误 | 重做这一处变换并逐字核验，口播里只讲一次 |
| 口播尴尬或推销腔 | 改成老师对学生说的平常话，删掉夸张词，载体不动 |
| 事实误导 | 改掉画面里表示错误机制的那个元素，不加免责句 |
| 动作不自然 | 换成该物件本来就会发生的动作 |

- 换皮判定：载体和断点仍未解决，只改措辞或换包装，就算换皮。口播本身被批评为生硬时，保留好的载体、修正措辞是合理的定向修改。
- 被否定的候选连同原因登记到本课反例清单，之后的 prompt 都带上。同一课最多修改两轮，仍被淘汰就返回空候选和具体原因。

## 8. 音频与画面试讲及反证
- 试讲重点听：是否因额外故事拖长；英文术语与缩写是否发音地道；停顿是否落在画面切换处。配音连续生成、停顿校准与片尾 Guard 执行见 [references/longform-voice.md](longform-voice.md)。
- 静帧检查：考点元素一眼可见，标签不超过 5 个，中英对照，变换只用箭头标一次。画面就近放置与安全区见 [references/video-production.md](video-production.md)。
- **评审反证核验**：不能盲目执行模型批评。对拼写错误或发音问题必须核对源文件、字幕与实际帧。经事实核查证实为模型误判的，坚决予以保留，不切碎长音轨。修证实的问题，保持整轨连续性。

## 9. 停止条件
当前课程的候选同时满足以下三点，即可进入制作试用：映射逐条核验通过；独立评审给出“仅供试讲”；音频和画面试讲没有遗留的具体问题。记录状态时写“已通过模型评审和试讲，用户尚未确认，未做真人学习测试”。成片经用户确认后方可记录用户认可，但不外推为真人学习效果。

## 附录 A：创作通用模板框架
```text
【角色与任务】
为中国医学生设计原创医学记忆钩子。本轮产出候选，交给独立评审与试讲；允许空结果。不自评分数，不用夸张词。

【输入清单】
1. 记忆目标：{{TARGET：记名字 / 准确拼写 / 配对 / 清单}}（若仅涉及拼写才逐字核验字母；其余可用俗名/近音/字形）
2. 考试实体：{{ENTITIES}}
3. 分诊依据：仅针对机制理解后仍易混淆的难点判定为 hook；能凭图解推导的判定为 diagram，无需口诀时返回空结果。
4. 正例拆解与参考：{{已授权参考课稿 + 正例结构拆解}}
5. 事实清单与反例：{{FACTS}}，严禁沿用 {{已登记反例}}

【输出类型 (JSON)】
- triage[]: point, decision(hook|diagram), reason
- candidates[]（最多 2 个）: id, hook_line, scene, teaching_lines[], mapping[]{cue, entity, type}, spoken_take, visual_caption, known_tradeoff
- no_candidate_reason: 若为空，写明试过哪些路径与断点

【停止条件】
同框 2-3 个实体，变换只讲一次，口播为人话短句，不带免责声明或推销腔，画面不表示错误机制。
```

## 附录 B：评审通用模板框架
```text
【角色与任务】
独立编辑盲审。只根据给定材料做结构与口语审查，不打分，结论仅为“仅供试讲”或“淘汰”。

【输入清单】
画面描述、一次讲解 teaching_lines、映射表、事实底稿、拒绝清单与反例清单（严格隔离作者身份、辩护与来源）。

【审查维度】
a. 正向检索：遮住映射，仅凭画面能否直接想起考试词。
b. 反向检索：给考试词能否回到画面。
c. 拒绝清单与反例：对照检查多跳、编造读音、推销腔或换皮。
d. 事实与口语：是否产生机制误导；是否符合真实讲课口吻。

【输出类型 (JSON)】
reviews[]: id, forward_breaks[], reverse_ok, reject_hits[], fact_issues[], speech_issues[], verdict, reason, failure_type
```
