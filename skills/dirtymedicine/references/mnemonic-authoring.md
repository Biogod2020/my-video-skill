# 记忆钩子创作工作流（mnemonic-authoring）

用于 dirtymedicine 课程中需要记住名字的考点。目标是一幕只用少量元素，老师讲解一次后，学生能凭画面想起考试名词。不要求每页都有口诀。

## 0. 运行规则
- 本 skill 的全部文字（流程说明和 prompt）由 agycli 起草。Codex 负责收集证据、核对事实与映射，并做针对性修订，不整体重写。
- 本机调用 agy 前，必须在同一个 shell 进程里先执行 `proxy`（这是交互式 zsh alias）：`zsh -ic 'proxy; agy ...'`。分成两条命令执行无效。
- 参考课程全文保留在私有工作区；按用户授权提供给写作或审核会话：不提交仓库，不写进 skill，不在公开输出中大段引用。skill 里只保留来源 id、时间点和一句结构说明。
- 依据当前任务和已有授权推进。项目目录信任不等于所有私人素材外发授权；已获授权的相同用途不重复询问。
- 不自评分数，不写「保证记住」「绝佳」，不把模型评审说成真人测试。

## 1. 选定记忆目标
1. 列出本课全部考点，分成 hook 和 diagram 两类：
   - hook：容易混淆、只讲机制仍难想起的名称配对或清单，例如病名↔镜下所见、毒物↔损伤部位、人名↔判例。
   - diagram：能沿因果链讲通的内容，例如通路、酶的作用方向、鉴别对比、检测原理。名字本身已经说明作用的（还原酶负责还原）不加比喻。
2. 为每个 hook 写明目标类型：记名字、准确拼写、配对或清单。
3. 只有拼写目标需要逐字核验字母，检查有没有多出、缺失或暗中跳过的字母。数字或字母如果原样保留、不经拼音转换，要明说。其他目标可以用学生已学过的俗名、英文名或近音作入口。

## 2. 读全文，拆正例
1. 确认每份来源都标为 STATUS=COMPLETE。缺了就写「缺失」，不用摘要冒充全文。转写错误不能当事实，品牌和医学事实要另行核验。
2. 创作前先填正例拆解表，只学结构，不照抄句子：

| 正例（来源/时间点） | 线索 | 考试词 | 连接类型 | 跳数 | 同框的东西 |
|---|---|---|---|---|---|
| DM-glutathione 13:20–14:10 | #6 quarter pounder / Heinz / bite | G6PD / Heinz bodies / bite cells | 字形重排 / 品牌同名 / 吃汉堡的固定动作 | 各 1 跳 | 一个汉堡、一瓶酱、咬一口 |
| DM-Heavy-Metals 31:25–31:40 | mango / basil | manganese / basal ganglia | 准确近音 | 各 1 跳 | 两种食材 |
| DM-Court-Cases 02:05–02:30、03:20–03:45 | dwarf 旁站着 superior / salGO 绿灯，车身写 Consent | Schloendorff 与 respondeat superior / Salgo 与 informed consent | 近音，再把原词写在画面里钉住考点 | 1 跳 | 一个角色或一辆车 |
| DM-Heavy-Metals 02:05–02:30 | arse / breath / poo | arsenic / 大蒜味口气 / 米泔水样腹泻 | 粗俗近音，一句话带出两条线索 | 1 跳 | 一句话 |

3. 从表中总结本课能借用的结构（例如「一件物品带两个考点」「原词直接写在物体上」）。

## 3. 多路径找载体
1. 先尝试几条不同路径的备选，再从中挑选，不把第一句直接扩写成故事。可选路径有：中文俗称或别名；品牌中文名或包装上的英文；课文、经典台词、国民级作品；日常惯例和物件本来就有的动作；准确的中英近音、字形或拼音首字母。
2. 优先选择同名、同字、可解释的近音、字形或固有动作，使学生在一次讲解后能直接找回考试词。如果学生得先记住「谁代表什么」（例如给司机、婴儿或某个角色起医学名字），通常增加了额外记忆负担，应优先改换载体。
3. 社会梗做删词测试：删掉梗后连接仍然成立，说明它只是装饰，删去；删掉后连接就断，才保留。荒诞、粗俗、冷幽默都可以，但必须承担联想。
4. 找不到合格载体时，写明是哪个实体、试过哪些路径、在哪里断掉。允许空结果。

## 4. 压缩成一幕
- 用一个本来就成立、或荒诞但一眼能懂的画面。角色不超过 2 个，同框扣住 2–3 个考试实体。可以有正常背景，背景元素不必都是考点。
- 一个物件可以带两个实体。数量与动作都须在画面里清楚成立。例如盘里有六个皮蛋，可以拿其中一个咬，避免口播变成同时咬下六个。
- 近音、字母重排、拼音首字母、对原词的最小改写，每种变换只讲一次，并在画面上用清楚的字母或拼音标出。不编错正式术语的读音。
- 口播分三段：先用一句人话描述画面，再给每个映射一个短句，最后用一句话转向机制页。时长依目标数量和实际试讲调整，简单钩子宜短，不能为了凑时长添加故事。
- 不写押韵四行诗，不写学术摘要式句子，不用推销腔挽救笑点（「超级好记」「极度黑暗」「大家只要在脑海里记住」）。

## 5. 机制与记名字分工
- 名字钩子页只负责让人想起名字。机制、诊断地位、诱因、遗传方式放到单独的机制页讲。
- 不编科学寓言（如「番茄酱就是变性蛋白」），也不把病理过程缩成画面（如「脾脏咬出缺口」）。
- 只有画面具体表示了错误机制或错误的诊断地位才修改。食物画面和正常吃饭动作不加免责声明。

## 6. 独立匿名评审
- 另开会话或换一个模型评审。只传入：画面描述、teaching_lines（一次讲解的内容）、映射表、事实、拒绝清单和已登记的反例。不传创作者的 known_tradeoff、辩护、模型身份和候选来源。
- 评审使用附录 B。结论只有「仅供试讲」或「淘汰」，附一句具体理由和失败类别，不打分。

## 7. 失败后定向修改
| 失败类别 | 改法 |
|---|---|
| 断链（某个目标词想不起来） | 只换这一个实体的载体，或把原词写到画面里的物体上 |
| 绕远或增加额外记忆 | 删掉中间角色或中间步骤，改用同名或固有动作 |
| 字母或读音错误 | 重做这一处变换并逐字核验，口播里只讲一次 |
| 口播尴尬或推销腔 | 改成老师对学生说的平常话，删掉夸张词，载体不动 |
| 事实误导 | 改掉画面里表示错误机制的那个元素，不加免责句 |
| 动作不自然 | 换成该物件本来就会发生的动作 |

- 换皮判定：载体和断点仍未解决，只改措辞或换包装，就算换皮。口播本身被批评为生硬时，保留好的载体、修正措辞是合理的定向修改。
- 被否定的候选连同原因登记到本课反例清单，之后的 prompt 都带上。
- 同一课最多修改两轮，仍被淘汰就返回空候选和具体原因。

## 8. 音频与画面试讲
- 用项目现有的配音流程把 spoken_take 生成试听，或真人录一遍。重点听：是否因额外故事或重复映射拖长；G6PD、Heinz、bite 等术语读得对不对；数字和字母有没有被读成别的；[pause] 是否落在画面切换处。
- 做一帧分镜或静帧，检查考点元素是否一眼可见。标签不超过 5 个，中英对照，变换只用箭头标一次。
- 发现具体问题，回到第 7 步按对应类别修改。

### 实际视听证据验证

脚本返回0或终端正常时仍可能是假成功。此前程序搜索`audio_accessible:true|false`时，曾误将自己贴的prompt/schema和正常UI快捷键提示当成评审完成。

**验证规则：**
1. 只匹配实际回复中的合法JSON布尔值（后面有逗号、`}`或`]`），且要在送出prompt后收到真正结果与`REVIEW_COMPLETE`。
2. 真实审核另有媒体附件确认，实听开头末尾引用及时间点，须保留实际附件确认、回复原始日志和模态可读取说明。
3. 不能把字幕读到当成音频可听，不能把ASR同音字当成配音错误。
主张具体证据，不写繁琐保守免责声明，不声称模型能验证真人记忆效果。

### 评审结论交叉核对

1. **多维核对与反证**：不能盲目执行每一条模型批评。必须核对实际MP4帧、源音波形、ASR与时间点。若模型误判（如误报无思考时间），应保存原评审与反证并记录理由，绝不能为凑通过而篡改评审。ASR同音字不能直接认定为配音错误。
2. **视听空间方位对齐**：必须把口播提到的左右、上下、前后等方位词，与实际图像位置一一核对。修复时，用GPTImage调整图像布局比切碎一条好的长音轨更适合本项目；修改后必须重新渲染并检查实际出片帧。
3. **无文本听写盲测**：排查能否真正听到声音时，可另送无字幕音频且不提供文本；客户端不支持WAV时，可用无文字画面的视频封装同一音频，让审核者直接引用听到的内容；但需明确这仍不能证明对真人的实际学习记忆效果。

## 9. 停止条件
当前课程的候选同时满足以下三点，即可进入制作试用：[映射逐条核验](../scripts/check_mnemonic.py)通过；独立评审给出「仅供试讲」；音频和画面试讲没有遗留的具体问题。记录状态时写「已通过模型评审和试讲，用户尚未确认，未做真人学习测试」。不写「用户已认可」，也不写学习效果。

## 附录 A：创作 prompt
```
【角色与任务】
你为中国医学生设计原创的医学记忆钩子。本轮只产出候选，之后交给独立评审和试讲；允许输出空结果。不自评分数，不用「绝佳」「保证记住」之类说法。

【记忆目标】{{TARGET：记名字 / 准确拼写 / 配对 / 清单}}
只有目标包含字母拼写时才逐字核验字母；数字或字母原样保留的，要明说。其余目标可以用学生已学过的俗名、英文名或近音作入口。

【考试实体】{{ENTITIES}}

【第0步 分诊】列出本课全部考点，逐条判为 hook 或 diagram，各附一句理由。只为 hook 创作。

【第1步 读全文、拆正例】先读下方完整来源，把给定正例按「线索 / 考试词 / 连接类型 / 跳数 / 同框的东西」拆开，只学结构，不照抄句子。

【第2步 找载体】每个实体至少走三条路径：中文俗称；品牌中文名或包装上的英文；课文、经典台词、国民级作品；日常惯例和物件本来就有的动作；准确近音、字形或拼音首字母。优先直接连接，避免连续的中转联想。禁止给任意角色起医学名字，禁止编造读音，禁止只起装饰作用的流行词（用删词测试判断）。

【第3步 合成一幕】角色不超过 2 个，同框 2–3 个实体，可以有正常背景。数量与动作要能在同一画面里清楚成立。每种变换只讲一次，用清楚的字母或拼音标出。画面只负责想起名字，不解释病理，不表示错误机制。正常吃喝动作不写免责。

【第4步 口播】先用一句话描述画面，再每个映射一个短句，最后一句转向机制页。按目标数量控制时长，写成一段，[pause 0.6s] 只放在自然停顿处。荒诞、粗俗、冷幽默都可以；不写押韵诗，不写学术摘要句，不用推销腔挽救笑点。

【拒绝清单】
- 用机制象征（电池、护盾、应援、解绑）冒充名称钩子；
- 把病理过程缩写成画面；
- 靠流行词撑熟悉感，或需要老师连续解释才能成立；
- 多跳载体，要求学生额外记住谁代表什么；
- 编造读音，或用容易读错的名字；
- 用推销腔挽救笑点；
- 没有具体错误却加免责声明；
- 每页硬配一个口诀；
- 把已被否定的反例换个说法重新提交。

【正例】{{来源 id + 时间点 + 一句结构说明}}
【反例（已被否定，不得沿用或润色）】{{本课反例清单}}
【事实】{{FACTS}}

【完整来源】只提供给已授权的写作或审核会话，不写进 skill，不放进公开输出。
<<START_FULL_SOURCE id={{ID}} SHA256={{HASH}} STATUS=COMPLETE|缺失>>
{{全文}}
<<END_FULL_SOURCE>>

【输出 JSON】
triage[]: point, decision(hook|diagram), reason
example_breakdown[]: example, cue, entity, connection, hops
candidates[]（最多 {{N=2}} 个）: id, hook_line, scene, teaching_lines[], mapping[]{cue, entity, type}, spoken_take, visual_caption, known_tradeoff
no_candidate_reason: 结果为空时，写明哪个实体、试过哪些路径、在哪里断掉
不要填写评审结论。
```

## 附录 B：评审 prompt
```
你是独立编辑。以下候选来自匿名作者。你只拿到画面描述、一次讲解用的 teaching_lines、映射表、事实、拒绝清单和反例清单。

对每个候选逐项检查：
a. 正向检索：假设老师已按 teaching_lines 讲过一次。遮住映射，只看画面描述，逐个判断目标词能否沿这次学过的连接直接想起；列出可能断掉的连接。这是结构审查，不是真人记忆测试。
b. 反向检索：只给考试词，是否有清楚的线索能回到画面。
c. 逐条对照拒绝清单和反例清单，包括是否换皮。
d. 事实：画面或映射会不会让学生记错机制、诊断地位、诱因或遗传方式。只有能具体指出错误才算问题，正常吃喝动作不算。
e. 口播：真实老师会不会这样对学生说话？有没有推销腔、学术摘要腔或硬撑的笑点？变换是否只讲了一次？读音是否正确？
f. 结论：「仅供试讲」或「淘汰」，附一句具体理由。淘汰时注明失败类别（断链 / 绕远 / 字母或读音 / 口播 / 事实 / 动作）和断点位置。不打分。

全部淘汰时，通过列表为空，并给出每个候选的具体淘汰原因。
输出 JSON：reviews[]: id, forward_breaks[], reverse_ok, reject_hits[], fact_issues[], speech_issues[], verdict, reason, failure_type
```
