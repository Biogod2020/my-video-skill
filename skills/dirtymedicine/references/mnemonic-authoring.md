# 独立口诀生成环节 (Mnemonic Authoring)

在医学教学视频制作中，将抽象复杂的知识点转化为易于提取的记忆钩子（检索钩子）是一项高度专门化的任务。一段好的口诀不仅仅是把八个字的医学机制缩句念出来，科学机制总结只是总结，并不等于助记钩子。

> **核心工作流声明**：每次生成或改写记忆口诀时，**必须脱离常规口播讲稿的润色，单独咨询 `agy`**。对于没有明确请求新口诀的纯润稿任务，不要求强行加戏编造口诀。已被用户否定的口诀应先交付新候选供审核，不把模型自评当作用户认可。

## 1. 口诀设计哲学与约束
- **强视觉检索钩子**：允许使用声音、字形、谐音、夸张的生活场景甚至荒诞的物理动作进行视觉联想。重要的是学员看得懂，且能在大脑中回忆出规范的医学名词。
- **中文语境的独立设计**：英文原课常用的首字母缩写在中文里往往毫无意义。除非部分英语的近音词对中国医学生同样友好，否则必须为中文语境设计独立可记的场景，绝不可机械硬译英语的首字母。
- **逐项可核对的事实映射**：视觉画面必须能一一对应回忆起规范的医学实体。医学生的错误机制不能被视觉联想强化（例如绝不能为了押韵把“供体”和“酶”在动作上搞混）。本方法论是一套设计向导，不额外编造医学事实，如实称其为设计方法，不虚假宣称已通过真人证实或保证记忆效果。

## 2. 真实原课口诀示例库
向模型咨询时，必须提供以下从原课提炼的真实示例，要求大模型模仿这种“视觉捆绑”的方式，而不是单纯发号施令给些抽象规则：

1. **SPIN F (氧化诱因)**
   - **出处**：[https://www.youtube.com/watch?v=bqfj4m9zKUM&t=450s](https://www.youtube.com/watch?v=bqfj4m9zKUM&t=450s) (07:30–08:20)
   - **视觉与映射**：Spin-off (近音 SPIN F) 的画面是一个转动的轮子，用来联想红细胞内部正常的抗氧化保护循环。S=sulfa drugs，P=primaquine，I=infection，N=nitrofurantoin，F=fava beans。
   - **边界**：这只是原课列举的常考氧化诱因示例，不是完整的药物禁忌列表。

2. **6GPD 汉堡 (形态与生化捆绑)**
   - **出处**：[https://www.youtube.com/watch?v=bqfj4m9zKUM&t=800s](https://www.youtube.com/watch?v=bqfj4m9zKUM&t=800s) (13:20–13:45)
   - **视觉与映射**：将 G6PD 重新排列为 6GPD。屏幕已核实的关键帧写道："Take a Bite of the #6 Guarter PounDer ("quarter pounder") with Heinz ketchup"，同时高亮 Bite、6 G P D、Heinz。学生脑中会浮现一个6号汉堡（对应病名），咬了一口（对应 bite cells），淋上 Heinz 番茄酱（对应 Heinz bodies）。
   - **边界**：咬痕细胞并不是 G6PD 单独确诊的铁证，不可在映射中暗示可以直接锁定缺陷。

3. **HMP (高 NADPH 需求组织)**
   - **出处**：[https://www.youtube.com/watch?v=UQfAKnXdBwg&t=475s](https://www.youtube.com/watch?v=UQfAKnXdBwg&t=475s) (07:55–08:20)
   - **视觉与映射**：利用通路缩写 HMP 进行字形绑定。Hepatic(肝脏)、Mammary(乳腺)、Periphery of adrenal(肾上腺皮质)。
   - **边界**：这代表典型的高需求组织，绝不能误导学生“PPP 通路仅在这些组织中存在”。

## 3. 授权、调度与迭代规范
- **运行方式**：在本机项目使用 CLI 时，必须在同一个 shell 中先启动代理。简短命令示例：`zsh -ic 'proxy; agy'`，随后提交填写后的完整 prompt。不写绝对路径；默认不代表允许上传新的私人参考录音。
- **语料授权**：已经获得授权使用的教材或课程文字，可以继续装载使用，不重复提问；若 prompt 需要全文但当前环境缺失，必须寻找实际已下载并确认授权的原稿。不要向用户谎称已附全文，严禁将完整的商业或公开课程字幕上传至公开代码仓库。
- **迭代与驳回**：如果模型的输出令人不满意（例如：没有视觉检索钩子、文化太生僻、映射含糊不清），请直接明确指出具体问题，让 `agy` 针对问题修改，并按用户反馈迭代。
