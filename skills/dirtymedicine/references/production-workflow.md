# 完整项目生产参考

本项目长课制作参考，单点润稿按请求范围执行。

## 1. 文本与提示词阶段
- **全文参考与 agy 写稿**：将已授权、实际取得的相关 BnB 与 Dirty Medicine 完整课稿、当前课程全文和用户反馈一并交给 agy，明确要求借鉴讲解推进、口语衔接及联想设计，生成原创课程并译写；不能只给“模仿风格”的抽象指令或用精选片段替代全文。记录源文件与完整性；超出上下文时分批保留全文和前后衔接，不宣称遗漏的文本已提供。
- **双语与全文映射**：双语课程先打磨完整英文稿，再逐段对齐生成中文口语；中文单语任务按所需语言直接写稿。确保医学逻辑在两套语言中的事实、数值及提示 cue 均不移位。不能仅处理摘录。
- **GPT Image 集成**：利用严谨的医学拓扑、方向指示及空间预留编写提示词，针对核心机制与对比图进行生图，生成的成品需经过详细的文本和逻辑重核。


## 2. 长课 TTS (MOSS)
- MOSS 作为项目中文长课当前优先选择，比较模型需使用相同的代表性完整长稿和相同参考音。留意前中后转场是否有漏读、重复、后半漂移。
- 冻结 seed 仅用于复现，不消除独立段韵律差。记录模型及 codec revision、参考音 hash、对应文本、参数、连续或上下文方式。
- 优先一次性连续生成。如需切段，通过文档确认历史上下文，并确认前缀已剥离。
- 先处理信息密度和原生节奏，不机械拖慢；整轨可用统一增益，不针对独立段归一化。
- MOSS 原生支持 `[pause X.Ys]` 标签，建议停顿仅是起试，以实际波形测量为准。ASR 首词跑到静音内部需校准答案揭晓边界。重剪声音须重算所有时间。

## 3. 视频验收与授权
- agy 实际 MP4 附件确认需结合看图判断能否读音，指出具体近似时间和句子。`audio_accessible:true` 和 `confident` 只是模型自述，不证明每段都已看清听到。
- 结尾截断说法若与 ASR 或源音频或成片音轨核对结果冲突，必须独立复查再修改。短片中间切尾不能推出全片截断。WAV 目前 CLI 1.3.0 不认媒体仅为版本观察；黑屏 MP4 封装已授权音频可减少字幕诱导，仍存在错分组时不能当作确定读音认证。需如实列出修改和听感待验点，不无限重做迎合 review。
- 上传授权已有可用即继续；新私有声音外发需核对实际用途、服务与授权，项目信任不是全部授权。凭证与 cookies 留在忽略的本地配置中；cookies 可能过期，按实际下载错误重新登录。不复制师资声音冒充。

## 4. Colab GPU 运维
- 仅有需要才使用 Colab。增加 `LD_LIBRARY_PATH` 条目时保留继承的驱动路径，避免覆盖后 GPU 不可见。
- LM 和 codec 顺序放置于 GPU 可省显存，不说成微调。
- 断开交互时先查后台任务和文件日志，避免重复。hash 分块针对大文件传输故障需要，不强迫所有资源分块。
- 下载验证完成即释放 GPU 会话；timeout 和有限重试若有新证据再试，无进展则切换路线并报告阻点。
- finally 仅清理自己创建的 PTY 子进程。运行记录按原项目根目录的相对路径查找；本地记录不随公有 skill 打包。


MOSS 原生停顿与 continuation 输入以 [官方模型卡](https://github.com/OpenMOSS/MOSS-TTS/blob/main/docs/moss_tts_model_card.md) 为准。转折可从 0.5–1.2 秒、题目思考从 2–4 秒、片尾从 1–2 秒试起，以实际波形和听感调整。如果有后期剪辑，记录改动并重算字幕、章节与画面 cue，不能声称音轨完全未改。

本机启动示例：`zsh -ic 'proxy; agy'`，在会话中提交完整 prompt。确认参考声的对应文字与输出前缀处理；不要只按参考音长度盲切波形。

## 5. 封面与图解覆盖

封面与图解覆盖：要求为医学系列生成独立封面；逐页检查图文匹配，尽量让每个机制/比较/临床表现/总结页有专门视觉，但测验页需保留完整题干且不得提前泄露答案。必须删除过去‘仅限3张图，其余纯文字’的硬性限制。严格核对图像左右方位与解说词一致，确保底部留有8%安全区不被字幕遮挡；图解生成后需真正接入成片时间线；最终成片必须经用户试听观看才算完成验收。

同一参考音、同一课程制作用途已有长期授权时，新建 Colab 会话或重生成仍按该授权继续；只有新素材或用途超出授权范围时才需确认。
