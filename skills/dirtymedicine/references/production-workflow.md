# 完整项目生产参考

本项目长课制作参考，单点润稿按请求范围执行。核心遵循 **Gemini/agy 贯穿创作与多模态审核闭环** 原则。

**运行环境与调用底线**：
- 本机调用必须先 `proxy` 再 `agy`：`zsh -ic 'proxy; agy ...'`。模型标识为用户指定的 `gemini-3.8-flash-high`，严禁擅自升级到 Pro。本地 CLIProxyAPI / loopback 代理服务须在端口与健康检查就绪后发起请求；若遇连接拒绝，进行有限重试并如实记录错误回执与实际响应，严禁将仅有连接拒绝记为实审通过，严禁盲目重启他人服务或改切模型。
- 模型调用记录须分列 requested model 与 returned model（例如请求 `gemini-3.8-flash-high` 实际返回 `gemini-3.8-flash-n`，按原样如实登记，不臆测映射逻辑）。
- 当网络或服务不可用时，如实记录哪个节点受阻，继续推进不依赖模型的工程与证据准备，严禁谎称已调用或由 Codex 私下完成教学创作代替。
- Codex 负责记录调用模型/会话、完整 prompt 或输入 manifest、实际附件回执、输出、反馈修改、最终文件 hash 和用户验收状态。凭证与私声绝对保密，不写入公开文件。规划、生成与实际审核分别记录状态；模型自述某项已完成时，仍需核对对应输出或实际附件评审回包，不能补记尚未产出的节点。

## 1. 文本与提示词阶段
- **全文参考与 agy 写稿**：将已授权、实际取得的相关 BnB 与 Dirty Medicine 完整课稿、当前课程全文和用户反馈一并交给 agy，明确要求借鉴讲解推进、口语衔接及联想设计，生成原创课程并译写；严禁只给“模仿风格”的抽象指令或用精选片段替代全文。记录源文件 `STATUS=COMPLETE` 与文件 hash 完整性；超出上下文时分批保留全文和前后衔接，不宣称遗漏的文本已提供。全段写作完成后，须把事实正确与口语连贯同时纳入连读验收。
- **局部改稿验收**：局部改稿要读取整课并处理受影响的相邻转场。完整保留原题不等于冻结旧解析的生硬转场。已获用户认可的口诀载体需要带回整段上下文整合语气再连读验收，不因候选更正式而抹掉已认可故事，也不直接把孤立候选插进成片。模型评审 PASS 是一条审核意见，不代表用户认可，也不证明对真人的自然度。
- **双语与全文映射**：双语课程共用医学事实底稿，生活语境与口语表达按目标听众分别改编；按 [spoken-chinese.md](spoken-chinese.md) 的本地化规则区分原题与自拟病例，核验医学等价、单位换算及音画对应。严禁仅处理摘录。
- **英文写作输入与验收路由**：后续所有英文课程统一以已获认可的 B02 IMG 简化版为语言难度基准（详见 [spoken-english.md](spoken-english.md)）。向 agy 提供提示词时，必须在私有环境中附带已获授权的完整简化课全文作为难度锚点（严禁公开打包散发私有全稿），并结合完整参考课与当前上下文联合提示；独立 Gemini 文稿审查须对实际发现的生僻普通词与长难句提供具体实例及修改建议，未发现时如实记录；简化完成后必须系统核查讲稿、字幕、visual cue、原题数据及选项与画面的时序映射；实际听审需确认初学者步调能跟上解释推导。本轮 B02 仅作为语言难度基准，局部节奏突变需客观看待，不作全轨无缺陷假设。
- **封面与图解覆盖**：为医学系列生成独立封面；逐页检查图文匹配，让每个关键机制、比较、临床表现和总结页拥有专门的高质量视觉；题页图不得泄露答案。GPT Image 负责直观形态与场景，原生层负责精确公式、标签与动态高亮；严格核对图像左右方位与解说词一致，标签就近放置于反应位点。

## 2. 长课配音与整轨听审
- **连续生成基线**：沿用实际已获认可的冻结 recipe。英文课程默认使用 MOSS-TTS-v1.5 8B 底模（`adapter_loaded=false`）原生生成，不加载 LoRA adapter，中文已验证 LoRA 权重保持独立有效；沿用同一授权参考声与既有英文教师 continuation 前缀（约 20 秒，seed 42），实际 `Instruction=None`，整课一次原生连续生成，严禁逐页分块拼接。详细基线规范与记录 schema 见 [moss-native-baseline.md](moss-native-baseline.md)。已获认可的原生轨默认保持原速；确有校准需要时，可基于实测发声速度另建小幅工程 tempo 派生轨，但必须如实记录 adapter 标识、原始生成轨与派生校准轨，重新对齐并校验字幕时间线。记录文本 hash、参考音 hash、前缀 hash、模型版本、seed、硬件环境与实际时长。冻结当前 recipe 旨在保障工程一致性，不封闭未来受控改进，亦不鼓励无休止盲目刷 seed。
- **整轨双轨审听**：配音生成后，必须将实际生成的完整长音频送交审查。普通听审可能漏检单音节缩写（如果糖代谢课 13 处 Pi 读音问题），因此必须执行自然度盲审（隔离真声、字幕、历史分）与专有名词/易错字专项审听（依据前置预设读法清单逐项核查位置与清晰度）的双轨制。盲审聚焦整体听感从容度、语气连贯与发音清晰度，严禁要求 LLM 判断局部数值语速突变或阈值，数值突变筛查完全由工程脚本负责；严禁仅提供文本或小样，严禁以字幕正确代替听音。
- **母带冻结与封装**：审听通过的音频母带即刻冻结，视频渲染直接封装已审最终母带文件，渲染器本身严禁私自二次拉伸、增益或拼接加工。严格区分 TTS 原生母带与经授权基于 sample 级 EDL 构建的稀疏留白派生母带，制作、工程验证、Gemini 听审与用户接受分别记录，未执行的步骤不得标为完成。
- **同语言统一语速与工程节奏校准**：所有课程同语言统一实际口播发声速度与停顿标准，由项目共享配置统一管理目标参数，严禁在代码中硬编码固定倍速。各轨先测量扣除静音后的发声速度；已获认可且符合当前标准的原生轨保持原速，确有校准需要时才计算派生轨倍速，倍速不同不代表标准不同；整段总时长或分钟字数不可替代纯发声速度。停顿覆盖句末落稳、设问、转场机制消化及正式题等全课教学结构。节奏校准与局部语速突变筛查采用确定性工程算法，所有数值计算、波形对齐与短窗对比无需且严禁额外调用 Gemini 决策或预先批准，严禁将此类数值证据交由 Gemini 裁决；边界结合讲稿、词级时间戳与实际波形共同验证，低置信度原样保留待核对，微弱呼吸不得因低 RMS 裁掉，仅近零中部可剪。所有字幕、高亮与 UI 统一映射，渲染不二次调速。最终导出音频与视频仍必须全量送交 Gemini 独立盲听与专项审听，落实初学者节奏结论；语速达标不能替代听感验收，若模型听审偶然指出急促感，须返回工程数据与人工上下文复听研判。新派生版本须独立复核，历史通过不移植。详细规范见 [longform-voice.md 停顿与顿挫规范](longform-voice.md#3-停顿教学目的与自动校准) 及 [local-pace.md 局部语速突变筛查](local-pace.md)。

- **音频时间轴与剪辑安全规范**：母带对齐与停顿/剪辑候选生成须遵循 [audio-timeline.md](audio-timeline.md)。中文使用 `scripts/prepare_qwen_alignment.py` 与 `scripts/run_qwen_alignment.py` 逐字对齐，英文使用全局 CTC，标准化后的外部句级转录由 `scripts/build_segment_edit_candidates.py` 检查；所有时间计算严格基于工程脚本与波形检测，本步骤仅输出候选；实际剪辑按既有授权范围制作 EDL 派生轨并独立审核。

## 3. 视频多模态验收与评审反证
- **实际完整 MP4 审核**：让 Gemini 3.8 Flash High 直接接收最终导出的实际完整 MP4 视频，从初学者视角全面检查：内容前置解释、图文空间对应、术语清晰度、病例线索分组、教学节奏与片尾留白。
- **核实附件与时间锚点**：核实媒体附件 ack 与可读取模态，提取片头、片中、片尾的实际发声台词引用与近似时间戳，结合 ASR、波形和实际帧进行交叉核验。视频验收正常包含字幕，不虚假声称盲听；末句引用不是保证每帧都看过，必须以实际证据核验。绝不把“代码执行成功”或“模型自述 confident”等同于视听无缺陷。
- **评审反证原则**：对模型的批评意见必须拆分为“实际观测事实”、“成因推测”与“改进建议”。批评事实必须以对应证据链反证：源字幕/ASS 验文稿字词，实际视频渲染帧验烧录字幕，波形验静音与剪辑点，实际听音验发音真伪。若模型出现误判（如误报烧录字幕文字、将原生重复推测为剪辑失误），调取真实证据坚决反证并记录结论，停止多余重做；严禁因 ASR 转写为同音字而盲目反驳实际正确发音。模型给出的时间戳仅作为近似定位参考，不冒称逐采样确认或真人试验。
- **真实缺陷重验闭环**：对证实的真实缺陷交由 agy 重新整合讲稿/分镜，Codex 重新导出成片，重新送审更正后的实际文件，核对交付文件 hash。用户最终明确验收即标志交付达成；交付验证未获用户明确反馈前，不得宣称用户已认可本片；无新问题时及时停止。

## 4. 片尾稿外音验收条件
- **验收条件**：整课音频结语后必须进行片尾 Guard 扫描（末 ASR 词后 0.5s 宽限，20ms 窗、-45dB RMS 扫描，累计 >=0.3s 活动触发听审）。详细算法与处理规范见 [references/longform-voice.md](longform-voice.md)。
- **纯尾裁复用**：核实结语后仅在安静区执行纯尾裁，且保留起点不变时，可直接复用已核验的 ASR 词级时间戳并更新文件 hash；头裁、插静音或修改正文必须更新对齐映射；若拥有可信的分段映射与时间平移关系，直接更新对应字幕与 cue 时间戳，无需盲目对全课无条件重跑 ASR。

## 5. Colab GPU 运维与授权
- **按需使用与断线恢复**：仅在本地算力不足时使用 Colab。断开交互时先查后台任务和文件日志，避免重复运行；设置有限超时与重试，有新进展再试，无进展则切换备选路线并报告阻塞点。
- **环境与释放**：增加 `LD_LIBRARY_PATH` 条目时保留继承的驱动路径，避免覆盖后 GPU 不可见；LM 和 codec 顺序放置于 GPU 省显存；下载输出并验证完成后释放自己创建的 GPU 会话；`finally` 块仅清理自己创建的 PTY 子进程。
- **长期授权效力**：同一参考音、同一课程制作用途已有长期授权时，新建会话或重生成按该授权继续，不重复提问；不推广为其他人的默认授权。私有凭证留在本地忽略配置中，严禁公开私人录音、参考音 hash 或绝对本机路径。
