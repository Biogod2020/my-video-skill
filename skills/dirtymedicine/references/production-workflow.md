# 完整项目生产参考

本项目长课制作参考，单点润稿按请求范围执行。核心遵循 **Gemini/agy 贯穿创作与多模态审核闭环** 原则。

**运行环境与调用底线**：
- 本机调用必须先 `proxy` 再 `agy`：`zsh -ic 'proxy; agy ...'`。模型标识为用户指定的 `gemini-3.8-flash-high`，严禁擅自升级到 Pro。
- 当网络或服务不可用时，如实记录哪个节点受阻，继续推进不依赖模型的工程与证据准备，严禁谎称已调用或由 Codex 私下完成教学创作代替。
- Codex 负责记录调用模型/会话、完整 prompt 或输入 manifest、实际附件回执、输出、反馈修改、最终文件 hash 和用户验收状态。凭证与私声绝对保密，不写入公开文件。 规划、生成与实际审核分别记录状态；模型自述某项已完成时，仍需核对对应输出或实际附件评审回包，不能补记尚未产出的节点。

## 1. 文本与提示词阶段
- **全文参考与 agy 写稿**：将已授权、实际取得的相关 BnB 与 Dirty Medicine 完整课稿、当前课程全文和用户反馈一并交给 agy，明确要求借鉴讲解推进、口语衔接及联想设计，生成原创课程并译写；严禁只给“模仿风格”的抽象指令或用精选片段替代全文。记录源文件 `STATUS=COMPLETE` 与文件 hash 完整性；超出上下文时分批保留全文和前后衔接，不宣称遗漏的文本已提供。全段写作完成后，须把事实正确与口语连贯同时纳入连读验收。
- **局部改稿验收**：局部改稿要读取整课并处理受影响的相邻转场。完整保留原题不等于冻结旧解析的生硬转场。已获用户认可的口诀载体需要带回整段上下文整合语气再连读验收，不因候选更正式而抹掉已认可故事，也不直接把孤立候选插进成片。模型评审 PASS 是一条审核意见，不代表用户认可，也不证明对真人的自然度。
- **双语与全文映射**：双语课程先打磨完整英文稿，再逐段对齐生成中文口语；中文单语任务按所需语言直接写稿。确保医学逻辑在两套语言中的事实、数值及提示 cue 均不移位。严禁仅处理摘录。
- **封面与图解覆盖**：为医学系列生成独立封面；逐页检查图文匹配，让每个关键机制、比较、临床表现和总结页拥有专门的高质量视觉；题页图不得泄露答案。GPT Image 负责直观形态与场景，原生层负责精确公式、标签与动态高亮；严格核对图像左右方位与解说词一致，标签就近放置于反应位点。

## 2. 长课配音与整轨听审
- **连续生成基线**：沿用冻结的 MOSS-TTS-v1.5 8B 底模与匹配 codec、已授权同一参考声、干净且节奏合适的教师 continuation 前缀，整课一次原生生成，无 LoRA、无整轨拉伸、无逐页独立声块。微调或小幅调速仅在控制变量的完整长稿比较中有明确收益时方可替代当前基线；记录原轨、处理记录并重新对齐。记录文本/参考音/前缀 hash、模型版本、seed、环境与实际时长。
- **整轨直接听审**：配音生成后，必须将实际生成的完整长音频交给 Gemini/agy 独立盲听，检查自然度、连贯性、语速、专有名词发音以及首尾完整性，并引用开头、中段、后段和末尾的真实发声词句与时间戳。不能仅提供文字稿或试听小样替代。审听会话须隔离模型身份、参考真声、字幕与旧评分。
- **教学停顿校准**：转场用短气口，难机制给吸收时间，正式题目作答前留足安静思考期并配动态倒计时。通过波形复核静音区，仅在确认的安静区补足纯静音并保存帧映射，保留所有发声采样，不掐字或段段归一化。

## 3. 视频多模态验收与评审反证
- **实际完整 MP4 审核**：让 Gemini 3.8 Flash High 直接接收最终导出的实际完整 MP4 视频，从初学者视角全面检查：内容前置解释、图文空间对应、术语清晰度、病例线索分组、教学节奏与片尾留白。
- **核实附件与时间锚点**：核实媒体附件 ack 与可读取模态，提取片头、片中、片尾的实际发声台词引用与近似时间戳，结合 ASR、波形和实际帧进行交叉核验。视频验收正常包含字幕，不虚假声称盲听；末句引用不是保证每帧都看过，必须以实际证据核验。绝不把“代码执行成功”或“模型自述 confident”等同于视听无缺陷。
- **评审反证原则**：对模型的批评意见必须用真实帧、ASR 和源音波形交叉反证。若模型出现误判（如误报字幕拼写或将清晰英文读音误判为汉字），保存证据坚决反证并保留正常音画，绝不为了迎合模型报告无休止重做或切碎整轨音频。
- **真实缺陷重验闭环**：对证实的真实缺陷交由 agy 重新整合讲稿/分镜，Codex 重新导出成片，重新送审更正后的实际文件，核对交付文件 hash。用户最终明确认可即标志成片交付达成；没有新问题时及时停止。

## 4. 片尾稿外音验收条件
- **验收条件**：整课音频结语后必须进行片尾 Guard 扫描（末 ASR 词后 0.5s 宽限，20ms 窗、-45dB RMS 扫描，累计 >=0.3s 活动触发听审）。详细算法与处理规范见 [references/longform-voice.md](longform-voice.md)。
- **纯尾裁复用**：核实结语后仅在安静区执行纯尾裁，且保留起点不变时，可直接复用已核验的 ASR 词级时间戳并更新文件 hash；头裁、插静音或修改正文必须重做对齐映射。

## 5. Colab GPU 运维与授权
- **按需使用与断线恢复**：仅在本地算力不足时使用 Colab。断开交互时先查后台任务和文件日志，避免重复运行；设置有限超时与重试，有新进展再试，无进展则切换备选路线并报告阻塞点。
- **环境与释放**：增加 `LD_LIBRARY_PATH` 条目时保留继承的驱动路径，避免覆盖后 GPU 不可见；LM 和 codec 顺序放置于 GPU 省显存；下载输出并验证完成后释放自己创建的 GPU 会话；`finally` 块仅清理自己创建的 PTY 子进程。
- **长期授权效力**：同一参考音、同一课程制作用途已有长期授权时，新建会话或重生成按该授权继续，不重复提问；不推广为其他人的默认授权。私有凭证留在本地忽略配置中，严禁公开私人录音、参考音 hash 或绝对本机路径。
