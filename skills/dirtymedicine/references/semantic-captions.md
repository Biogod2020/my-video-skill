# 语义字幕编排与多模态工程校验规范

本规范规定医学视频教学中语义字幕的规划、对齐、静音延留与多模态自动化校验标准，防止机械字数切分导致断句破碎、字幕闪退及答案提前泄露。

---

## 1. 语义字幕规划原则 (agy 职责)

1. **整段语义切分与自然断行**：
   - 严禁在旧字幕单元或固定字数内机械硬切（彻底避免出现标点掉至下一行、生化动词截断、词语生硬拆开以及末尾出现零点几秒孤字闪烁的情况）。
   - 由 agy 基于整段连续口播进行语义编排，支持 1–2 行人工语义断行。
   - 必须完整保留口播全文、规范标点与医学专有名词，字幕编排严禁擅自删改口播字句。
2. **中英文分流与时轴挂靠**：
   - **中文**：基于 Qwen ForcedAligner 字符级时间戳进行逐字顺序对齐；
   - **英文**：基于既有全局 CTC 词级时间戳进行精准对齐，严禁大模型推测词秒；
   - **术语规范显示层映射**：医学专有名词与缩写（如 G6P、NAD+、NADH、LDH 等）在屏幕规范显示层与发音层必须显式建立发音与屏显映射字典，严禁使用模糊推测。
3. **案例演进说明（非全课硬指标）**：
   - 在 B03 样片实践中，旧算法固定字数切割导致 23 处短间隔闪空及末尾孤字“应。”仅显 0.16s；通过 agy 语义编排与逐字顺序匹配，实现单条时长更充裕、内部无闪空且 AAC 音频字节完全一致。各课时长与条数依据实际口播确定，不作为机械常量。

---

## 2. 短静音延留与结构化边界

1. **短静音平滑保持**：
   - 语句间自然短静音期间，字幕保持显示直至下一条字幕起始，消除因气口微停导致的视觉频闪与闪空。
   - 字幕延留仅调整屏幕呈现区间，严禁触碰、截断或变速音频波形。
2. **结构化边界与答题隔离**：
   - 长停顿、章节转场、换题及思考留白区必须设置明确的字幕截止时间点。
   - 设问与练习题进入思考期时，严禁将包含答案解释的字幕延留进入思考留白区。
3. **母带 EDL 强绑定**：
   - 字幕时间戳必须映射至同一 EDL 派生后的冻结最终母带。若音频重新生成、重新对齐或应用了剪辑，必须重新计算全套时间轴，严禁复用陈旧时间戳。

## 3. 工程校验流水线与放行标准 (Codex 职责)

由工程脚本执行确定性校验与字幕生成：
```bash
python scripts/build_semantic_captions.py \
  --language zh-CN \
  --lesson lesson.json \
  --alignment alignment.json \
  --plan caption_plan.json \
  --audio master.wav \
  --fps 30 \
  --font NotoSansSC.ttf \
  --out build/captions/ \
  --aliases aliases.json \
  --config caption_config.json
```

脚本输出 `timed.json`、`captions.srt` 及 `checks.json`。只有 `checks.json` 全部硬指标通过方可进入后续流程：
- **顺序无损**：逐字顺序零漏字、零重复，发音别名显式映射全量命中。
- **排版合规**：行首无前置标点，无尾行孤字闪现（<0.2s 孤字残存），医学专有名词严禁跨行折断。
- **时间线单调性**：字幕时序严格单调递增，字幕块之间无时间重叠（zero overlap）。
- **参数配置化**：单条显示时长与短静音最大延留阈值由配置文件管理（例如短片模板初始筛查值通常设为 1.2s–7s，短静音延留上限通常设为 1.0s），各项目依规范配置，不设死板常量。
- **视音频时钟与安全区**：合成帧率实际 fps 与场景局部渲染时钟严格统一；字幕必须基于实际终端渲染帧核查安全边距，确保不遮挡课件图表、分子结构或选项区域。

## 4. 多模态实审与机械校验分工

1. **双重验收互补**：
   - Gemini 3.8 Flash High 接收实际完整 MP4 视频，侧重初学者视觉节奏、阅读舒适度与音画空间同步。
   - 大模型视频分析受采样率限制，低频抽帧容易漏检单帧闪烁或瞬时字幕，模型通过不能替代工程机械校验。
2. **数值与时序以脚本为准**：
   - 模型给出的时间戳不得超出视频实际总片长；
   - 字幕行间显示顺序、持续秒数及重叠判定不能只采信模型自述文本，统一由 `scripts/build_semantic_captions.py` 的 checks.json 作为数值裁决基准。
3. **抽查实帧与边界**：结合脚本输出，重点抽查密集术语帧、切题思考过渡帧以及每段首尾边界帧，核对字幕与实际渲染一致。
