# 长轨音频输出完整性与必要修复

本规范用于指导长轨连续语音生成（TTS）、音频完整性审查、局部缺陷修复及全链路交付验证，确立“审听归审听、工程归工程”的严密闭环。

## 1. 核心定位与职责分工
- **职责边界不混淆**：审校模型负责讲稿实质写作、语义准确性与全轨媒体实听质检；工程系统负责精确采样点、时轴计算、声学特征提取与哈希校验。严禁让审校模型裁决或批准具体采样点与数值切点。
- **缺陷定级原则**：细微修辞优化属于可选建议（Optional）；真实存在的重复念诵、漏读、关键专业词汇误读及声画断裂属于阻断性缺陷（Blocking），必须闭环修复。

## 2. 生成性重复筛查与双轨确认
- **指标假象甄别**：正常 EOS 结束符、单一解码块（single decode block）以及零剪辑的母带 EDL 记录，均不能证明音频不存在模型生成性重复。即使原始生成 WAV 与母带哈希完全一致，仍可能包含连贯且未经剪辑的长段幻觉重复。
- **独立 ASR 候选初筛**：采用未提示目标文本（unprompted）的独立 ASR 转写并与标准脚本比对，作为异常区间筛查工具。严禁因专业术语的常规同音字误差机械否决整轨；亦不可仅凭整体文本相似度高而忽略局部长插入、漏读或重复区间。
- **听觉真实性核验**：所有 ASR 标记的疑似异常必须通过全轨实听确认。审校方若推测异常原因（如误判为“剪辑拼接失误”），工程系统需依据一致的生成回执与文件哈希纠正成因归因，但必须采纳听觉确认的重复事实，且严禁篡改原始审校记录。

## 3. 最小化局部修复与时轴映射
- **母带与回执保全**：执行任何修复前，必须对原始 Native 母带、原始 ASR 结果、对齐数据及审核回执进行持久化存档。
- **高保真样本级切除**：仅在独立确认真实重复后进行局部手术式修复。切点必须由工程系统基于实际声学词轴与波形过零点/静音间隙精确选取。保留区域的 PCM 数据必须逐位不变（bit-exact），严禁施加重采样、音高修正或时间拉伸（tempo）。
- **词轴偏移与重对齐**：
  - 若切除区域纯属模型幻觉重复，未包含任何预期的正文声学单位，可根据样本偏移量对后续已有词轴进行精确位移重映射；
  - 若切除涉及标准正文单位或边界声学混叠，必须重新运行声学强制对齐或按成功参数全轨重新生成，严禁采用线性插值估算。
- **闭环与重生成策略**：删除重复绝不等于回退为逐句生成拼接；局部修复后须生成新旧哈希对比、修复 EDL 及前后声学审查记录闭环。派生新母带必须独立送交 Gemini 全量实听完整新音频与实看完整新 MP4，用户反馈高于模型 PASS，严禁向新 hash 移植旧审核状态。

## 4. 文本派生与前置映射拦截
- **别名碰撞拦截**：若发音字典将缩写无差别展开为全称，会导致“全称 or 简称”在合成时被连续朗读两次相同全称。必须在 TTS 前端流水线引入校验逻辑，拦截词表替换冲突，由写作端制定合理发音映射，工程端验证，严禁直接删减原稿或伪造字幕。
- **衍生变更与 DAG 传导**：发音映射调整属于衍生文本变更。当标准讲稿字面不变但发音配置变更时，流水线按 DAG 级联触发：重新验证发音映射、TTS 合成、音频母带、强制对齐、字幕生成与成片渲染；已通过且未变更的规范事实审查记录予以保留，不虚假冒充重审。优先以相同超参数重生成完整连续音轨，避免为了单处读音破坏整体语流。

## 5. 字幕节奏调整与门禁严谨性
- **文本不变与语义拆分**：遇到单组字幕停留时间超标时，应通过语义切分断句拆为多组，严禁擅自删改讲稿字词标点，更严禁为迁就字幕节奏而人为调慢音频或强行插入静音。
- **诊断模式与交付门禁隔离**：诊断工具的宽容检查结果必须明确标注 diagnostic_only，严禁将诊断通过误认作最终发布（Release PASS）。交付必须以严格模式下的全项工程校验为准。

## 6. 基础设施健康与凭据安全
- **长任务与凭据防护**：在向外部计算节点上传私有素材或启动长轨任务前，必须前置校验实例与内核健康状态。复用相同素材与既定用途的长期授权，不作冗余重复询问。
- **日志脱敏与泄漏处置**：连接报错及标准输出流仅保存在本地被忽略的私有日志中；向交互界面与工具链汇报时，仅允许输出白名单状态码与错误分类，严禁打印携带临时认证参数的 URL。一旦发生临时凭据外泄，必须立即终止销毁对应实例使其完全失效，并保持其他独立会话不受影响。
