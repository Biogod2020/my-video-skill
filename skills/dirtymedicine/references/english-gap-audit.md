# 英文长课原生停顿审计与局部安全缩短规范

本规范记录英文长课（MOSS-TTS 原生连续生成）停顿审计（Gap Audit）、气口实听复核与局部安全缩短流水线。发声速度检测因扣除静音，无法诊断气口过长；“原生”亦不代表“天然自然”。本规范用于在母带发声和音色已获认可的前提下，排查并局部修正原生过长停连，保护真实发声与呼吸，不冻结所有原生空隙。

## 1. 核心认知与经验背景

- **问题起因与定位纠偏**：在 B-01 英文课中，用户反馈“already made. When the signal arrives”处停顿不顺且不止一处。上一轮 Codex 误将该问题归咎于两道题后期的 3.76 秒人工补白并予以删除，但目标锚点依然生硬。经全文字级时间轴精确定位与 EDL 溯源，确认该处实为原生 CTC 词间 2.86 秒过长停顿。
- **发声速度与停顿审计分工**：常规发声速度检测扣除了静音，无法诊断气口过长与停顿断裂，因此必须独立执行停顿审计（Gap Audit）。
- **时长引导的日志推断**：对比基线（底模、采样 seed、文本、前缀、参考声、硬件与 engine 均一致），主要输入差异为当前的额外 `duration_condition`（5550 tokens，早期无时长条件），整课从 360.72 秒膨胀至 433.04 秒；词间总间隔增加 54.54 秒（注：CTC 间隙不等于纯静音），按统一 RMS -20dB / 20ms / -43dB / 0.18s 口径扫描，低能量区间净增 36.3 秒。由此日志支持推断：时长引导可能把额外预算分配给了句末过长静音。但这仅作为有据推断，不声称严格证明，严禁将关闭 duration_condition 设为全局默认。

## 2. 停顿审计与复核流程 (Gap Audit Workflow)

1. **锚点精确定位与 EDL 溯源**：用户反馈具体语句停顿不顺时，首先依据全局 CTC 词时间轴获取精确时间戳，核对当前点是否包含后期 EDL 插入，严防误判归因。
2. **全篇长间隔与异常候选扫描**：对全音频扫描长间隔候选（如 >=0.75s、>=1.5s）以及短间隔/词内异常。所有数值阈值仅用于生成待审候选列表，严禁直接触发自动裁切。
3. **Gemini 独立全量实听逐项复核**：严禁用开头、中段、片尾四句话的 PASS 证明每个气口自然。Gemini 必须实际听完整录音，对所有长间隔候选逐项结合语境复核：
   - 区分教学必要的思考停顿、看图观察期、段落换气与生硬拖沓的冗长空隙；
   - 必要思考/读图/呼吸必须保留，严禁按固定统一秒数全盘裁平；
   - 英文文稿本身通顺时，坚决不为修停顿而盲目改写台词；
   - 经实听确认确有缩短必要的点，标注 `necessary_edit: true`、`necessity_reason`；由工程设置 `target_gap_seconds`，不以模型估秒决定剪辑时间。

## 3. 工程确定性缩短与多模态同步 (`shorten_course_gaps.py`)

整轨音频波形裁剪由确定性工程脚本执行：
```bash
python scripts/shorten_course_gaps.py \
  --audio narration.wav \
  --alignment narration.ctc.json \
  --plan gap-shorten-plan.json \
  --out narration_shortened/
```
- **Plan 数据规约**：输入音频需有同名 `.json` 元数据；JSON 计划必须包含 `source_sha256`、`alignment_sha256` 以及 `cuts[{word_index, left_word, right_word, necessary_edit: true, necessity_reason, target_gap_seconds}]`。剪辑 settings 工程阈值由课程独立配置决定，严禁由 LLM 裁决数值。
- **双重波形安全检查**：仅对有明确上下文复核记录的项应用缩短。算法仅删除低能量区间的中部；在 CTC 左右词边界前后施加保护窗，并执行 RMS 与 Peak 双重低能量检查；裁剪两端选择波形近零样本点（near-zero samples）以减小接缝跳变，仍须复听确认无爆音。低能量不代表绝对无呼吸；静音带不足时脚本停止并报错，应在计划中将该点改为保留后重跑。
- **无损与多模态重映射**：所有保留波形 PCM 满足逐样本绝对相等（sample-exact identity）；严禁使用全局 tempo 变速或局部语音重生。脚本导出新 alignment 与 sample-level EDL，后续渲染流程再以这套映射重新生成字幕、画面与章节时间戳。
- **交付验收**：派生全轨新音频由 Gemini 独立全量实听，新 MP4 完整视听验收，用户预览确认后再更新公开视频。

## 4. B-01 课程实测复核记录（历史记录非通用参数）

- **数据测量**：原生总长 433.04 秒；全课扫描出 53 个 >=0.75 秒间隔候选（候选不等于缺陷），其中 20 个 >=1.5 秒；用户锚点处 CTC 词间间隔达 2.86 秒。
- **听审复核**：Gemini 完整听审整轨音频并逐项复核 53 处候选，建议 14 处 shorten（含用户锚点）、39 处 keep（保留正常教学留白与自然呼吸）。
- **剪辑结果**：14 处必要缩短累计剪除 33.3008 秒低能量空白，发声样本全量逐样本保留，两道题邀请思考后的间隔及其余未剪气口原样维持。此数据仅为 B-01 实际记录，严禁作为通用参数机械移植。
