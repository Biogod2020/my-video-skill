# 中文教学口播表达与改写规范

本规范用于指导医学教学讲稿的中文口播撰写。目标是像一位经验丰富的老师，在黑板或示意图前给身边的学生指着画面一步步讲解，因果逻辑严密，摒弃空话套话与审核公文腔。

---

## 1. 核心口播原则

1. **术语紧跟动作**：保留考试必需的学术专名；专名出现后立即用动词交代其催化或转化去向，不连环堆砌生涩名词。
2. **区分设问场景**：
   - **机制解释中的自问自答**：针对学生最易产生的疑问具体设问，即时回答，快速点明机理。
   - **正式练习题**：先完整读出题干和选项、留出思考时间（如 `[pause 3.0s]`），再揭晓与解释。
3. **讲清共有特征为何难以鉴别**：在鉴别诊断时，说明重叠体征为何均可出现，引导学生转向特异性分界点。
4. **自然重述关键关系**：难点拆解完毕后，使用规范术语自然总结一次核心因果，加深印象。
5. **条件紧邻结论，保留真实可能性**：
   - 改变当前答案或推导的真实条件（如酶活性、负荷、用药），必须放在相关动作/结论处解释。
   - “保留真实可能性”和“分层排除”是科学标准，但不应变成每页都念的免责声明或缓冲套话。
   - 避免把“耗尽”“完全没关系”“有药就选”“一定不会错”当成自然的肯定语气。对条件敏感的真实知识不能只靠删限定词或移到备注来隐去。
6. **语速与停顿贴合认知**：生化转化分步走，每交付一个动作留出短暂气口（如 `[pause 0.6s]`），让画面展开与声音同步。
7. **分工隔离**：
   - **口播正文**：正向说明老师如何接着上文、指图讲动作和回答学生此刻的问题。依据语句在当前推理中的作用判断是否保留：“明确一点”“注意”等本身不是禁词，不用词语黑名单取代连贯性判断；判断的是它是否解释了学生此刻需要理解的条件、动作或区别。真正改变当前答案的条件放在相关讲解里。
   - **事实底稿**：用来核对约束与条件。
   - **备注 (teacher_notes)**：存放与当前答案无关的作者审核意见、支线及作者说明。

## 2. 课程开头与自然引入
- **简短问候与问题聚焦**：用自然简短的问候开场，基于已知信息进行自我或课程介绍，明确提出本节课要解决的一个具体问题。
- **避免突袭**：完整课程先交代主题与学习目标，再进入病例；片段改稿或题目专讲按所需安排导入。
- **中立身份**：未提供讲师姓名时使用通用欢迎语，绝不伪装为 Dirty Medicine 等官方讲师。

## 3. 连续叙述与跨段转场
- 转场取决于知识内容，不要强制每课套用相同页数或固定步骤。同一知识线可由机制过渡到比较，再推向综合题目，解答完一次病例后可自然过渡到换一个实验条件的教学假设。
- 不要把“现在另看一道题”当成推理上的唯一承接；应用已有逻辑推演新条件。
- 局部改稿必须读取整课上下文，处理受影响的相邻转场。完成后，须把事实正确与口语连贯同时纳入连读验收。

## 4. 文本翻译与双语处理
- **双语先后次序**：优先输出完整、连贯的英文原稿，然后再完整进行中文口语译写（纯中文任务依需求单出）。
- **映射而非直译**：逐段映射事实、数值、问题与图表 cue；绝不能使用机器般的逐句生硬翻译。
- **全文本底**：严禁把全文静默压缩成摘录。遇超长文本，需分批带上下文处理或保留完整附件。
- **名词与缩写配对**：屏幕重要名词须附带中英全称与缩写。旁白首次提及时，用动态语言解释机制，之后自然使用中文或缩写即可，不必强迫中英文每次都读双份。数字和单位必须严谨确证。单独维护重要术语的中英全称、缩写与预期读法，检查 TTS 实际输出；屏幕显示完整英文不等于旁白必须读双份。

## 5. 新手病例解题逻辑
- **完整呈现基础**：先给足完整的题干与选项文字。
- **提供基础解题工具**：补充理解解题所需的药物基本用途或生化指标含义，但不扩散成冗长的全科用药指南，药物用途举例 ≠ 患者本身的特定诊断。
- **寻找共性与特异性线索**：先通过共有表现识别对应的综合征群，再抓取能定位特定机制的特异性线索。线索要在屏幕上随逻辑逐步高亮，绝不提前标红正确选项。机制提示 ≠ 疾病确诊。
- **按层级排除**：回到设问本身的层级，逐个解释干扰项为何不匹配。

## 6. 正向课程改稿 Prompt 框架
当需要改写课程或片段时，参考以下正向框架（不必将其扩写成冗长的负面规则清单）：

```text
【教学目的】明确本次讲解的知识目标。
【完整上下文/完整来源】提供前后的口播稿或事实来源，确保转场承接自然，不偏离已知信息。
【事实底稿】列出不能改变的医学条件、原题文字、数据与反应方向。
【交付口播和备注分离】口播以面对面指图教学的语调，动作紧跟术语；将与当前主线无关的支线或模型纠错的审核意见放入 teacher_notes。
```

自然指图衔接、动作句与关键关系的改写，按需读 [spoken-examples.md](spoken-examples.md)。

生成口诀时单独咨询 agy，按 [mnemonic-authoring.md](mnemonic-authoring.md) 提供真实原课示例与完整参考稿。
