# 中文教学口播表达与改写规范

本规范用于指导医学教学讲稿的中文口播撰写。目标是像一位经验丰富的老师，在黑板或示意图前给身边的学生指着画面一步步讲解：通俗交代转化动作，准确保留学术专名，因果逻辑严密，摒弃空话套话。

---

## 1. 核心口播原则

1. **术语紧跟动作**：保留考试必需的学术专名作为核心认知，专名出现后立即用动词交代其催化或转化去向，不连环堆砌生涩名词。
2. **具体设问，即时回答**：进入复杂节点时，针对学生最易产生的疑问自问自答，快速点明机理，不搞悬而不决的虚张声势。
3. **讲清共有特征为何难以鉴别**：在鉴别诊断时，说明重叠体征（如红肿、部分实验室指标升高等）为什么在不同疾病中均可出现，引导学生把注意力转向特异性分界点。
4. **自然重述关键关系**：难点拆解完毕后，使用规范术语将核心因果自然总结一次，随后在表格或题解中再次复用，形成稳固记忆。
5. **条件紧邻结论**：阐明系统在基础状态下的应对能力，将诱因（氧化负荷、药物、饮食）作为边界条件明确交代；在具体转化环节保留真实可能性，顺畅推导失衡过程，不堆砌连篇缓冲套话，也不夸大推断。
6. **语速与停顿贴合认知**：生化转化分步走，每交付一个物理或化学动作留出短暂气口，让视觉画面的展开与声音讲解同步。
7. **改后逐项核对**：改后逐项对照原稿的主语、动作、反应方向与条件，防止流畅而改变所讲对象。

## 2. 课程开头与自然引入
- **简短问候与问题聚焦**：用自然简短的问候开场，基于已知信息进行自我或课程介绍，明确提出本节课要解决的一个具体问题。
- **避免突袭**：完整课程先交代主题与学习目标，再进入病例；片段改稿或题目专讲按所需安排导入。
- **中立身份**：未提供讲师姓名时使用通用欢迎语，绝不伪装为 Dirty Medicine 等官方讲师。

## 3. 文本翻译与双语处理
- **双语先后次序**：优先输出完整、连贯的英文原稿，然后再完整进行中文口语译写（纯中文任务依需求单出）。
- **映射而非直译**：逐段映射事实、数值、问题与图表 cue；绝不能使用机器般的逐句生硬翻译。
- **全文本底**：严禁把全文静默压缩成摘录。遇超长文本，需分批带上下文处理或保留完整附件。
- **名词与缩写配对**：屏幕重要名词须附带中英全称与缩写。旁白首次提及时，用动态语言解释机制，之后自然使用中文或缩写即可，不必强迫中英文每次都读双份。数字和单位必须严谨确证。单独维护重要术语的中英全称、缩写与预期读法，检查 TTS 实际输出；屏幕显示完整英文不等于旁白必须读双份。

## 4. 新手病例解题逻辑
- **完整呈现基础**：先给足完整的题干与选项文字。
- **提供基础解题工具**：补充理解解题所需的药物基本用途或生化指标含义，但不扩散成冗长的全科用药指南，药物用途举例 ≠ 患者本身的特定诊断。
- **寻找共性与特异性线索**：先通过共有表现识别对应的综合征群，再抓取能定位特定机制的特异性线索。线索要在屏幕上随逻辑逐步高亮，绝不提前标红正确选项。机制提示 ≠ 疾病确诊。
- **按层级排除**：回到设问本身的层级，逐个解释干扰项为何不匹配。

## 5. 消除“免责公文腔”与元指令分离
- 在具体转化环节保留真实的可能性，将诱因作为明确边界条件；不要使用“可能通常大概某种程度”的连环废话缓冲。
- 不随意编造必然发生的关系或夸大“看到就秒杀”的成功保证。
- **元指令分离**：确保用于指引画面或逻辑的旁注提示（如“绝不使用保守词”）完全隔离于口播文本外，防 TTS 误读。
