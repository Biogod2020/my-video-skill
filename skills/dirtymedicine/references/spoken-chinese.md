# 中文教学口播表达与改写规范

本规范用于指导医学教学讲稿的中文口播撰写。目标是像一位经验丰富的老师，在黑板或示意图前给身边的学生指着画面一步步讲解，因果逻辑严密，摒弃空话套话与审核公文腔。

---

## 1. 核心口播原则

1. **建立问题动机与因果连贯**：
   - 展开机制或疾病讲解前，必须先讲清该主题的问题动机或生理生存任务（如生化机制课交代细胞面临的潜在氧化威胁或能量刚需，疾病鉴别课交代临床易混难点），再顺畅引出反应动作、催化步骤以及失衡后的后果。
   - 用已讲逻辑顺畅承接后续的横向比较与综合练习，不生硬割裂知识线。
2. **术语紧跟动作**：保留考试必需的学术专名；专名出现后立即用动词交代其催化、转化、转运或清除去向，不连环堆砌生涩名词。
3. **初学者解题工具前置**：
   - 在需要学生推理做题之前，先行交代药物的基本用途或化验指标含义（例如：氨苯砜可用于皮肤病，但此处关键在于增加氧化负荷）。
   - 面对复杂化验单，先按临床思维分组引导理解（破坏指标组、免疫方向组、机制线索组），再给出思考期；答案解析时直奔题眼，不要再次照本宣科通读所有数值。
4. **区分设问场景**：
   - **机制解释中的自问自答**：针对学生最易产生的疑问具体设问，即时回答，快速点明机理。
   - **正式练习题**：先完整读出题干和选项、分组点拨线索、留出明确思考时间（如 `[pause 5.0s]`），思考结束后先用自然过渡句平稳承接，再揭晓答案并解释。
5. **讲清共有特征为何难以鉴别**：在鉴别诊断时，说明重叠体征为何均可出现，引导学生转向特异性分界点，避免非此即彼的武断排除。
6. **自然重述关键关系**：难点拆解完毕后，使用规范术语自然总结一次核心因果，加深印象。
7. **条件紧邻结论，保留真实可能性**：
   - 改变当前答案或推导的真实条件（如酶活性、负荷、用药），必须放在相关动作/结论处解释。
   - 依据语句在当前推理中的作用判断是否保留：“明确一点”“注意”等本身不是禁词，不用词语黑名单取代连贯性判断；判断的是它是否解释了学生此刻需要理解的条件、动作或区别。真正改变当前答案的条件放在相关讲解里。
   - 避免把“耗尽”“完全没关系”“有药就选”“一定不会错”当成自然的肯定语气。
   - 绝不输出泛泛的免责声明或缓冲套话作为每页口播；与当前推导无关的作者审核话与辩护，一律放入备注（teacher_notes）。
8. **语速与停顿贴合认知**：生化转化分步走，动作间留出短气口（如 `[pause 0.35s]`）；难机制给吸收时间；正式题目作答前留足思考期（如实测 5 秒）。

## 2. 课程开头与自然引入
- **简短问候与问题聚焦**：用自然简短的问候开场，基于已知信息进行自我或课程介绍，明确提出本节课要解决的一个具体问题。
- **避免突袭**：完整课程先交代主题与学习目标，再进入病例；片段改稿或题目专讲按所需安排导入。
- **中立身份**：未提供讲师姓名时使用通用欢迎语，绝不伪装为 Dirty Medicine 等官方讲师。

## 3. 连续叙述与跨段转场
- 转场取决于知识内容，不要强制每课套用相同页数或固定步骤。同一知识线可由机制过渡到比较，再推向综合题目，解答完一次病例后可自然过渡到换一个实验条件的教学假设。
- 不要把“现在另看一道题”当成推理上的唯一承接；应用已有逻辑推演新条件。
- 独立实验题明确告诉学生这是“独立的生化实验假设”，考察环路局部细节，而非上一题病例的追加检查。
- **由 agy 统一整合转场**：局部改稿必须将整课上下文送回 agy 处理受影响的相邻转场，Codex 不能私自拼接。完成后，须把事实正确与口语连贯同时纳入连读验收。

## 4. 文本翻译与双语处理
- **双语先后次序**：优先输出完整、连贯的英文原稿，然后再完整进行中文口语译写（纯中文任务依需求单出）。
- **映射而非直译**：逐段映射事实、数值、问题与图表 cue；绝不能使用机器般的逐句生硬翻译。
- **全文本底**：严禁把全文静默压缩成摘录。遇超长文本，需分批带上下文处理或保留完整附件。
- **名词与缩写配对**：屏幕重要名词须附带中英全称与缩写。旁白首次提及时，用动态语言解释机制，之后自然使用中文或缩写即可，不必强迫中英文每次都读双份。数字和单位必须严谨确证。单独维护重要术语的中英全称、缩写与预期读法，检查 TTS 实际输出；屏幕显示完整英文不等于旁白必须读双份。

## 5. 新手病例解题逻辑
- **完整呈现基础**：先给足完整的题干与选项文字，保留原始数值与条件。
- **提供基础解题工具**：在作答前引导学生对化验单指标分组（破坏指标、免疫方向、机制线索），但不过度扩散成冗长的全科指南。
- **寻找共性与特异性线索**：先通过共有表现识别综合征群，再抓取特异性诱因与特征形态定位特定机制。线索在屏幕上随逻辑逐步高亮，绝不提前剧透答案。
- **按层级排除**：回到设问本身的层级，逐个解释干扰项为何不匹配。

## 6. 改稿通用模板框架
当需要改写课程或片段时，采用以下精简框架（输入清单 + 输出类型 + 停止条件）：

```text
【输入清单】
1. 教学目的：本次讲解的核心知识与认知目标。
2. 完整上下文：前后相邻段落或整课稿件，确保转场逻辑连续。
3. 事实底稿：必须严格保持的医学条件、原题文字、数据与反应方向。
4. 用户指定要求：明确受影响的局部范围与保留的认可内容。

【输出类型】
- 口播稿：面向学生指图讲解的口吻，动作紧跟术语，自然承接相邻段落。
- 教师备注 (teacher_notes)：与当前口播推导无关的背景核查、说明与支线。

【停止条件】
医学事实无移位、受影响范围精准修改、相邻转场连读自然顺畅、未引入套话或免责公文腔。
```

自然指图衔接、动作句与关键关系的改写，按需读 [spoken-examples.md](spoken-examples.md)。
口诀创作单独调用 agy，按 [mnemonic-authoring.md](mnemonic-authoring.md) 执行。
