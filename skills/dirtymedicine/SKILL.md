# Dirty Medicine 教学讲稿与视频制作

将复杂的医学机制、疾病鉴别与考试题解转化为因果清晰、画面逐步展开的教学视频讲稿与分镜方案。重点讲清概念混淆、机制变化与做题排除，避免平铺直叙照读教材。

需要参考完整口播文稿、分镜推进表或试题标注格式时，请阅读 [references/examples.md](references/examples.md)。

本机 skill 或课程稿由 agy 起草，Codex 负责证据核验和定向微调。调用 agy 前，先在同一交互 shell 中运行 `proxy`。已有授权有效时不重复提问；项目信任不等于新私人素材外发授权。

## 1. 核心制作准则

- 完整课用简短问候、已知身份或课程介绍引入主题与具体学习问题；片段改稿或题目专讲按任务需要安排导入。文本连贯性与具体语调规则详见 [references/spoken-chinese.md](references/spoken-chinese.md)。

- **术语紧跟动作**：保留规范的医学专名、酶名与生化指标；出现专名后立即说明其催化、转化、转运或清除动作，不把多个生涩名词挤在同一句话中。
- **指出具体难点**：不使用夸大承诺的话术；在容易混淆的地方，指出具体的辨析要点。
- **自然重述关键关系**：讲完复杂的转化机制后，用规范术语自然总结一次核心因果；随后在表格或题解中再次调用，加深印象。
- **交代条件与推导**：改变酶活性、负荷或药物作用等条件，说明哪一步跟不上、后果是什么；只有主题确实涉及缺陷时才加入失衡情形，不要求每课都是病理故障；改变当前答案或推导的真实条件，放在相关动作/结论处解释，不把可能推导说成必然发作。
- **分层排除选项**：解题时区分计算与机制矛盾、缺乏关键证据与两病皆有的共有特征；不把非必需的典型表现缺失当作硬性排除依据。

## 2. 需求对接与交付边界

- **文案润色**：当用户仅要求润色文案时，区分明确要求的原文结构与事实：原题文字、数据、条件、对象与反应方向必须保持；当用户要求衔接或整合时，允许在范围内重排解释次序并优化过渡句，但不自动把单句修改扩大为整课重写。不从技能示例套入额外对象或病理。
- **文件修改**：当用户请求修改具体文件时，直接更新目标文件及其必要镜像，并保留旧稿，不在聊天框中只给口头建议。
- **全案设计**：在用户明确要求制作视频脚本或分镜方案时，按教学模式规划口播、画面推进与分镜表；优先对接项目已有的视觉规范或脚本格式。
- **原题保留**：涉及试题解析时，完整保留用户提供的题干与选项文字，在原题上做重点标记与选项旁注。局部改稿保留原题不等于冻结旧解析的生硬转场。

## 3. 制作步骤

### 第一步：选定教学组织模式
根据内容属性从 [references/teaching-patterns.md](references/teaching-patterns.md) 中选择匹配路径，并参考模式之间的自然承接。

### 第二步：撰写口播脚本
按 [references/spoken-chinese.md](references/spoken-chinese.md) 撰写；需要跨段推进与具体改写对照时，读 [references/spoken-examples.md](references/spoken-examples.md)：
- 采用面向学生指图讲解的口吻，以动作串联生化转化。
- 解释机制时，遇到易混点采用具体设问并紧跟即时解答；正式练习题则先完整读题与选项。
- 语速与留白根据认知负荷调整，避免公文腔。

生成或改写记忆口诀时，请先选择有价值的难记目标再决定创作，普通总结不要冒充口诀。确定需要后，单独咨询 agy，把真实 Dirty Medicine 口诀、对应知识点与已授权完整参考课稿一起放入 prompt，明确要求模仿其联想设计。读 [references/mnemonic-authoring.md](references/mnemonic-authoring.md)。先明确要记的是名称、拼写还是配对；将候选交给独立匿名会话审查，再用实际音频与画面试讲核对，模型通过不等于用户认可或真人记忆效果。已确认的口诀在候选咨询后带回整段上下文，由 agy 整合语气，再连读验收，不把候选直插成片。

### 第三步：设计画面逐步展开分镜
参考 [references/video-production.md](references/video-production.md) 的分镜协议：
- 保持核心图解或表格空间位置稳定，元素赋予全局 ID。
- 通过口播文字 cue 触发元素显示（初始 `initial_visible: false`）与高亮。
- 屏幕短标签仅保留实体名称、生化动作与核心判据，深入解释交给口播。
- 未录音前仅注明建议时长排程与前后关系，不填写虚构的精确秒数。

### 第四步：事实与证据核实
- 涉及药物靶点核实激动剂/类似物与抑制剂属性，比值指标按阈值数学逻辑表述，事实溯源详见 [references/evidence.md](references/evidence.md)。
- 真实图片素材必须确认成像与染色方法，未确认时注明待核实，机制图明确标为机制示意图。
